# PHB 2014 兼容插件模板

可直接在应用的“规则插件”页面下载并安装：

`public/plugin-templates/phb-2014-compat-template.dndstars5e`

模板本身只包含原创演示内容，不包含《玩家手册》规则文字、名称、表格或美术资源。你可以在拥有相应内容授权的前提下，用自己的数据替换演示定义。

当前纵向切片覆盖：

1. 单文件安装、SHA-256 固定、浏览器本地持久化和 Worker／WASM 隔离执行。
2. `registerFeature` 人物卡特性选择。
3. 地图中的友方目标选择。
4. 动作经济、所有权、阵营和30尺距离的 DM 权威校验。
5. 白名单 Headless 临时生命值 capability、ACK 与共享角色状态同步。

插件文件必须自包含，不能使用静态或动态模块加载，也不能访问 DOM、网络、浏览器持久化或页面 Store。DM 上传后，当前房间玩家会自动下载、校验并在隔离 Worker 中激活完全相同的文件。
