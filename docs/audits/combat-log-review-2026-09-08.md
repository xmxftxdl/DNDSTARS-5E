# 战斗日志审查与修复（2026-09-08）

## 本次四项修复

1. **效果触发依据**：Activity 执行器仅为实际满足条件的结果分支生成日志依据，包含规则名称、分支与操作编号、豁免/攻击结果、选项及规则前提。效果事件在产生时保存名称、来源、持续时间和状态；事务边界补充结算动作及同目标此前发生的结果。此前结果明确标为关联事实，不冒充因果条件。
2. **统一事件覆盖**：补齐原先遗漏的 85 类事件。全部 184 类战斗事件均有显式中央处理。新增类型若未补日志，目录审查测试会失败。覆盖包括怪物机制、死亡区域效果、持续伤害、战技、超魔法、反应、预备动作等。
3. **结构化骰值可见性**：Activity 日志携带投骰者、目标、骰值、加值与合计；玩家可见性按投骰者集合决定，不再正则解析日志文字。自定义检定编号不会影响明暗骰判断；随机颜色骰与伤害骰归施法者；对抗双方独立处理。普通字符串不能授予骰值可见性。
4. **动态名称快照**：从运行时注册表解析特性、法术、资源、物品与怪物名称，并保存到事件快照。插件卸载或更名后，已生成日志仍保留原名。未注册内容显示“未命名特性/规则项（编号：…）”，保留可排查编号，不编造翻译或机制。
