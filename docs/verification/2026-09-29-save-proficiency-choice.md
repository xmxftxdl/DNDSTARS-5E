# 永久豁免熟练的条件选择

本批补充通用 `select.options.requiresSavingThrowProficiency`，没有按法术或子职名称分支，也没有调用转换 API。

## 语义与边界

- 条件为属性与严格布尔 `proficient`，最多六条，不接受重复属性、未知字段、错误属性或空数组。
- 检查本内容应用前的永久熟练；本内容的固定授予与选定授予不用于满足自身条件，临时豁免熟练不写入永久人物卡。
- 与原有组间选择依赖同时成立。Host 原子校验，失败时不修改人物卡。
- 界面共用资格函数，按升级提交顺序预览之前有效内容的授予；修订使用升级前快照。
