# 缓慢术施法入口回归（2026-09-15）

## 实现范围

按本次实际消耗一个动作的施法判断，不按角色种族、怪物 ID 或法术白名单判断。

- 普通玩家核心施法：保留种族施法、物品施法、迅捷法术和职业动作转换的原有判定；新增前置检定，延迟时直接返回，不再提前收集命中、豁免、伤害或反制骰。
- 玩家裁定法术：在裁定请求/叙事投掷之前检查。
- Activity 法术：在 Activity 执行、效果及骰子生成之前检查；权威引擎也拒绝跳过检定的提交。
- 怪物自动与人工裁定施法：共用前置检定。传奇动作施法不作为普通一个动作的施法处理。
- 附赠动作、反应、仪式及长时施法不被误加此 D20；原先明确仅扣法术位、不消耗动作的叙事例外保持原约定。

## 结算与恢复

新流程：D20 1–10 继续；11–20 消耗当前动作并保存原始施法意图，当前不结算法术效果。到该单位后续回合的恢复阶段重新校验目标与资源，再投后续骰子、支付完成动作及施法资源。施法资源在完成时扣除一次。失效或取消的恢复请求会被清除。

记录跟随具体地图棋子保存，支持拟像等共享角色资料的独立单位。成功结算时原子清除记录；旧版本已支付资源的延迟施法记录仍走兼容路径，避免重复扣款。
