# 道具 Headless 接入与核查（2026-09-11）

最新进展见 [第二批接入记录](batch2.md)。当前目录 717 项；以下第一批数字保留为历史记录，最新统计见 summary.json。

## 第一批落地

- 治疗药水和神莓改用与法术相同的 Headless 治疗函数；保留禁止治疗。玩家 HP 归零（包括普通伤害溢出）不直接死亡，死亡豁免失败达到三次后普通治疗无效。救起时重置死亡豁免，只移除归零来源的昏迷，保留其他来源的昏迷。
- 医疗包：选择濒死角色，消耗一次使用使其稳定；不恢复 HP，不复活死亡目标。
- 火球魔杖、闪电束魔杖：复用法术结算、DC 15、3—9 环与对应充能消耗，以及已有充能恢复/最后充能规则。
- 隐形药水、水下呼吸药水、十种伤害类型抗性药水：有时限的 ActiveEffect，隐形在攻击/施法后解除。
- 水上行走、羽落、行动自如戒指及十种抗性戒指：根据装备、鉴定、同调状态投影被动效果；卸下时删除。羽落戒指被动不因一次落地被消耗。
- 为工坊道具协议增加稳定濒死、使用后持续效果、装备被动声明及校验。

## 验证

- 8 个测试文件共 550 项通过：库存、魔法道具、协议、法术来源、战斗引擎、治疗回归、接入测试和目录审计。
- 补充抗性戒指实际受击测试：10 点火焰伤害实际扣除 5 HP，而不只是检查效果对象存在。
- 5273/5274 实房间 UI：DM 发放隐形药水；玩家背包从 29 增至 30 格；点击使用后回到 29 格，玩家角色显示 invisible；DM 角色检视同步显示 invisible。
- 本轮网页验收仅覆盖上述发放/使用/状态同步路径，不代表全部道具均已逐件进行双端结算测试。测试法师当前留有本次隐形效果，测试药水已消耗。

禁止治疗的例子包括冻寒之触造成的暂时无法恢复生命值，以及效果明确声明的 preventHealing。0 HP 本身不是禁止治疗；死亡则另外由三次失败判定。
