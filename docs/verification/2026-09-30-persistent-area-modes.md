# 持续区域模式的选择、暂停与恢复

## 实现范围

本批新增封闭 `modes` 与 `change-granting-area-mode` 通用操作，支持初次选择、后续以 Activity 切换、暂停和恢复。同一区域保留 ID、来源、范围、专注和到期时间；切换替换当前模式的六类机制字段，暂停清除这些活动字段而保留后续活动授权。Host 保存所有模式的 DC、方向和触发豁免快照，核对真实来源和活动授权，并保存变更事务记录。

存档迁移以模式状态重新投影活动字段，拒绝不合法模式；暂停状态不会因残留 blocking 值重新获得机制。有限总次数和每目标一次的触发收据在其他模式、暂停、刷新、回合推进与战斗重基时保留。专注结束及原期限到期仍清理区域。升环统一作用于活动和非活动模式，不在切换或恢复时重复应用。

同批修复区域 occupantModifiers 标准化不满足往返一致性的问题：标准输出不再写入随后会被严格校验拒绝的空可选规则数组；原有输入校验没有放宽。

不修改原始 AI 草稿；付费 API 调用为零；未修改实际 5273/5274 房间。
