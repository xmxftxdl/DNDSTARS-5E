### 通用接口与一致性

- 生成物品由来源效果拥有；客户端不能伪造来源属性、施法环阶或重复发放。直接 Authority 的受限召回要求 Host 完整库存名册。
- 箭袋和武器效果跟随具体实例，不因物品名称相同而转移；附魔选择、弹药消费和次数使用同一容器。
- 注册模块编译器和直接 Headless 提交均支持命令、契约和效果共享；不存在只在单元级解析器中有效的另一套配置。
- 坐骑的旧实体检查契约实例，而不只检查法术名称。暂时遣散保留契约；改换形态或类型前必须永久解除。
- 动态语言选项由 Host 自己的角色快照重建。编辑器保存现有武器的专属属性，避免编辑名称后丢失自动化字段。
- 增加普通箭袋和弩矢匣库存模板；战士和通用攻击面板均提供投掷/投石索入口。
