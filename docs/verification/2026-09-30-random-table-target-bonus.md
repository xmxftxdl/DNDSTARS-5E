# 施法后随机表共享伤害池验收

## 实现

Host 随机表的 self-centered-core-spell 结果保留一份基础伤害骰池，每个实际目标分别读取来源限定伤害修正。修正在原始骰池中相加，然后归零，再由公共法术豁免结算器处理成功豁免及防御。日志记录每个目标实际应用的加值，未修改基础共享骰池。

该路径已先过滤有限魔法免疫；本批没有扩大随机表支持的结果类别，也没有把未实现的表项改成自动化。

## 验证

新增 7 项行为验证：同来源、其他来源、暂停效果、成功豁免加抗性/易伤、非法后续目标豁免、非法共享伤害骰。使用强制触发表及耗尽的关联资源，验证失败时恢复待处理表、生命值和资源；成功后 JSON 往返重放同一动作被拒绝。

首次运行因测试在强制触发分支额外提供 triggerRoll 被正确拒绝；修正 fixture 后，3 文件 367 项通过（含 308 项 Headless 主回归及 41 项原生法术来源伤害测试）。完整 npm run typecheck 通过（23287 exit 0），定向 diff 检查通过，全部验证进程已结束。日志为 .codex-logs/random-table-target-bonus.txt 与 .codex-logs/random-table-target-bonus-types.txt。
