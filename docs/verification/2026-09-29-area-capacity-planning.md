# 区域容量规划与排出距离

本批延续区域携带与高度同步，核对本地缓存的碧水球条目 `:171:5`。缓存原文具有不同体型容量及超额随机排出要求，不能仅限制一次触发的目标人数。

## 已接入的接口

`forcedMovement.mode: nearest-outside-area` 可声明 `maximumOutsideDistanceFeet`，正整数 1–1000。共享地图规划器按完整占格离开区域、落点占格至区域格的最近距离筛选；距离上限不等于从原位置开始的移动距离。受阻或无范围内落点会拒绝整笔区域触发，不保留伤害、状态或回执。普通 push 声明此字段会被拒绝。

声明经过规范化、源 DC 转换、模块导出读取安装及 Activity 执行后仍保留。SDK 和 AI 结构化指南已说明语义，不允许拿此字段假装容量自动化已完成。

## 开发中的容量规划器

`persistentAreaCapacity.ts` 是尚未接入触发事务的确定性 admission 规划器，未对模块暴露容量字段。容量单位按六种体型显式定义；未知/不支持体型拒绝，不猜中型。规划使用 Host 提供的 1-based 随机结果；没有结果时返回候选 ID、骰面数与 drawIndex，而不是按地图顺序选择。候选排序固定，相同结果可重放，多次选择无放回，唯一候选无需随机结果。已有目标重复进入不重复计量。

当前规划策略保留新进入者，随机排出现有目标直至容量满足；混合体型可能需要多次排出。这是明确的算法策略，尚未认证为碧水球全部原文语义，不能据此升级法术完成状态。需要接入目标的有效实例状态、Host 随机请求、多个合法落点联合规划、精确移除来源状态、倒地及原子提交。直接调用底层纯规划器不等同于游戏内流程完成。

## 后续接入：容量事务

已将上述明确策略接入触发器 `capacity` 声明和共享区域事务。规范化只允许束缚条件使用该声明，策略和字段严格校验；合成模块导出、读取、安装及 Activity 提案保留容量数据。

准备阶段将地图生物纳入临时 Headless 快照，包含未参加实际先攻的乘员，缺失绑定角色资料则拒绝。结算按当前有效、同来源、同区域实例的束缚及区域相交筛选占员。Host 协调器请求显式随机值，复算复用同一前缀，不调用隐藏随机数。页面初次结算和 DM 最终调整均使用此协调器；纯伤害备选预览仍不主动掷容量骰。

排出逐个规划互不占用的落点，使用标准效果移除生命周期处理（含剩余移动力和后继效果）与标准倒地入口，写入带高度的 forced moved 事件。任一落点无效、垂直高度改变或受保护束缚无法移除，整笔返回原状态和空事件，不提交先前规划的排出或新目标状态。

专项事务六项验证已通过：无随机结果不写入，非先攻乘员、来源状态隔离、多目标不同落点、后续受保护目标导致全笔回滚、成功豁免/DM取消束缚不掷容量骰、同事务骰值复用及非法随机值拒绝。完整回归及类型检查记录见主进度日志。仍未用原始 PDF 自动重转、双端浏览器或原文全语义证明碧水球完成。

## 后续：区域结束解除容量束缚

新增 `reconcileDnd5eEndedAreaCaptives`，仅依据前后地图确认已删除的容量区域实例，在临时 Headless 状态内通过统一移除入口清理其束缚。使用原始效果集合，暂停效果也清理；来源与实例双重匹配，不移除其他区域或独立持续状态。投影只写回实际变化的 Token/角色，避免规范化无关目标。共享区域/专注对账在无专注关系时也执行此清理，DM 手动删除路径在已有失去支撑坠落事务前调用，并合并释放事件及角色变化。

初验两项断言误读 Token.conditions（实际状态保存在 activeEffects），修正为检查持久化效果投影。区域与容量两文件90项通过：area-end-captives-final-20260929.txt。类型及删除/坠落回归结果见主进度日志。

本批只处理结束时的束缚解除，不代表碧水球落地/摔倒/熄火完成。跨地图无本地图 Token 的角色结束广播、其他删除入口完整覆盖仍需审查；不能仅因新对账辅助函数存在就认定所有生命周期入口完成。
