# DM 确认时调整 D20 模式

确认区上方提供优势、正常、劣势，默认采用当前模式。伤害骰和局部重投不显示；自由投掷继续跳过 DM 确认。

正常切为优势/劣势保留第一枚、由 DM 补投一枚；后续切换复用骰池。切回正常采用第一枚。补骰期间禁用编辑、模式切换和确认，结束战斗后的异步结果不再更新确认请求。

DM 模式裁定复用现有骰面修正接口。由于挂起的调用方已准备好原始模式，模式改变时将采用值写入其原有骰位，避免调用方按旧模式再次选出另一点数。真实骰池和最终模式保留于骰盘、公开结果与单独的 DM 裁定记录；Headless 原始动作事件仍表示原模式的修正骰位，不是新投掷的骰池。
