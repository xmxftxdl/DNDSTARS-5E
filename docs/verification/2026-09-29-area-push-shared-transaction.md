# 区域推离共享结算验收

原有 `push-from-source` 在页面提交区域效果后修改地图，缺少 Headless 位置和位移事件，不能作为独立模块共享结算的完整证据。页面 `always` 分支也未排除拒绝触发的机会。

现在 `resolvePreparedDnd5ePersistentAreaTrigger` 统一处理推离和最近区域外排出。规划器复用原地图方向选择及碰撞约束，返回实际距离；事务一并更新 Headless 位置、forced moved 事件、空间关系、地图与回执。页面二次推移已删除。保留兼容地图投影函数，但它也委托共享规划器。

- 5文件179项初验178通过/1失败：`area-push-shared-20260929.txt`。失败发现缺失地图来源会触发 mapBridge 异常；修复为事务入口检查 Token 完整性，返回原态、空事件及 invalid-target。
- 修复后2文件89项通过：`area-push-shared-final-20260929.txt`，与初验重叠。包括三种触发条件和两种豁免结果、HP、位移事件、移动力不消耗、地图与Headless一致、重载回执、完全受阻、拒绝机会、缺失来源原子失败。两种位移模式均验证超出擒抱距离后清理关系并返回事件。
- 合成模块导出/安装/Activity执行测试保留两种位移声明和来源DC。几何测试、原Activity地图交互测试在首批通过。
- 定向 `git diff --check` 通过；类型检查结果见主进度日志。
