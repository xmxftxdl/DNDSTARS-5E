# 魔绳术地图入口验证（2026-09-11）

实现：魔绳术选择施法者 5 尺内的一个 5×5 尺地图格，创建非专注、600 轮的持续绳子入口。施法不直接为周围角色添加状态。玩家点击入口提交进入／离开请求，由 DM 权威验证角色归属、距离、体型和八人容量。重复进入被拒绝；离开与入口删除／失效都会清除对应空间状态。角色卡显示“异次元空间（魔绳术）”。

## 验证

- 5274，JCB9PVAHWYJH 房间，R2 全法术测试法师：临时以魔绳术替换迷踪步准备。点击相邻地图格，生成一个绳子入口，DM 端持续区域列表显示“魔绳术（1 格）”；消耗一个二环法术位与动作，没有额外的 DM 场景确认。
- 玩家点击绳子进入，占用人数从 0/8 到 1/8；离开后恢复 0/8，DM 收到交互日志。
- 第一次实测发现状态实例删除后旧条件投影会残留。修复为统一写入 ActiveEffect、schemaVersion 与 conditions 投影。
- 第二次实测确认玩家人物卡显示“异次元空间（魔绳术）”；5273 删除绳子后，5274 人物卡显示“当前没有状态效果”。
- 测试期间 5273 服务中断，重启后恢复正常。第二次测试结束后使用服务器 R2 检查点恢复战斗资源及状态；移除测试新增法术，重新准备迷踪步。法术书恢复 60 条、准备 25/25。
- Vitest：ropeTrick、playerActionAuthorityRouter、mapInteraction，43 项通过。
- TypeScript：tsc -b --pretty false 通过（rope-trick-types-release.txt）。
- Vite build 通过。新增模块及 authority router 的定向 ESLint 通过。

## 范围

本次实现用户要求的选格入口与多人状态交互。绳索具体长度、爬行所耗移动力、收绳与空间结束后的掉落位置／伤害仍由场景裁定，未声称完成这些自动化。空间隔离复用现有暂离位面条件，未新增独立室内地图。未执行 5275 的独立玩家浏览器操作；多人容量、其他角色进入与归属校验由测试覆盖。
