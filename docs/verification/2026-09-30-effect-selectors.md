# Source-owned effect alternatives

Added a closed `active-effect.anyOf` declaration for named-effect alternatives and semantic-tag alternatives. It is mutually exclusive with the existing single effect ID. Every tag in an alternative must be on the same effect, and `source:self` must match that effect's authoritative source actor. Different effects cannot supply ownership or tags for one another. New selectors exclude suspended effects for both ID and tag matches; legacy single-ID semantics remain compatible.

The Actor snapshots used by registered Activity authority, compiled handlers and the Headless core projection carry Host-derived suspension state. Strict validation bounds alternatives and tags, rejects mixed or unknown selector fields, duplicates within tag lists, invalid IDs, empty lists and oversized declarations. SDK and AI conversion instructions describe both semantics and missing-source-effect dependencies.

Synthetic evidence is in `dnd5eActivityEffectSelectors.test.ts`: named/wrapped IDs, alternative tag order, wrong/unknown owner, incomplete or split tags, split ownership, suspension, active alternatives, unrelated ID substrings, missing effects, inverse predicates, actor subjects and any-source selection. The module is exported, reinstalled, and tested through registered and compiled Host entries and the map feature facade. Tests check effect eligibility before damage/action consumption and preserve input state.

This supplies the qualification primitive required by Maddening Hex's curse-source clause. It does not certify the original generated configuration or tag existing curses by name. Originating effects must declare their own tags or have explicit IDs. Source-specific grant dependencies, primary-target area anchoring, compulsory primary damage and selected neighbors remain to be integrated/verified. No API calls or real-room changes; no browser certification.
