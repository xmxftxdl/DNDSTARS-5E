# 武器及战技共享来源加值领取记录

## 改动

引入仅在Host内部流转的 Dnd5eWeaponDamageRollBudget。一次武器攻击的主骰、已有附加伤害及后续战技骰共享 claimed 标记，即使当前来源加值为零也记录已经存在该骰池，避免后续重复领取。该对象不在玩家动作协议、存档或插件输入中暴露。

普通命中后战技沿用主攻击记录；反击及指挥攻击分别为实际出手者创建独立记录并传入嵌套武器结算，再结算战技骰。主伤害为固定值且此前无骰时，战技骰可领取来源加值。第二目标保持独立骰池。
