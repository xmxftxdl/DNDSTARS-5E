# DM 单位高度设置

- 入口：DM 选择玩家或怪物 → 管理 → 飞行高度。
- 输入离地高度，转换为地图绝对高度保存；支持升降 5 尺、落地。使用现有地图 token 更新与房间发布链路，不扣移动力、不授予飞行能力。
- 校验有限数值、非负离地高度、绝对高度上限与三维单位占位；允许上下相接，不允许体积重叠。属于 DM 位置修正，不模拟升降路径或坠落伤害。
