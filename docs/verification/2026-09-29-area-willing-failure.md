# 持续区域自愿豁免失败

## 来源与缺口

缓存PDF来源 `0996cf1c03dffb49c5d0cf4777c0d1e4c27eda75f32dd1ff8ff82afc99ddd38b:171:5`（碧水球）明确允许大型或更小生物选择豁免失败，Huge及更大自动成功。对应诊断 `2bb7f930b1a408852655516847729df59879046d950ef42bd5da89a10760cf7d` 指出区域没有自愿失败字段。现有Activity同名接口不能自动使持续区域支持这一机制。

## 实现

- `savingThrow.allowWillingFailure` 经声明、规范化、插件校验、来源DC及模块归档保留。非法非布尔值被拒绝。
- Host共享选择窗口向目标角色或DM询问，默认继续豁免。未声明允许或适用体型自动成功时不显示选择；运行时也再次校验。
- 一次触发的批量豁免和最终结算共用一个选择，新的触发重新询问。来源可拒绝触发时先询问来源，不能提前要求目标掷骰。
- `willingFailure:true` 不请求或消耗d20，保留预备下次优势，结算正常失败分支。日志区分自愿失败和DM覆盖。没有把来源施法玩家的目标同意声明当作授权。
