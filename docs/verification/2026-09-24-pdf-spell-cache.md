# PDF 法术内容缓存与 Headless 预检

同一应用地址、同一浏览器配置下，按 PDF 原始字节 SHA-256 复用缓存。文件名、修改时间和房间不是内容标识；其他浏览器／其他站点地址不会共享此缓存。

IndexedDB 存放提取窗口、原文、职业清单、AI 草稿和断点。房间仅保存当前 PDF 的引用，不重复存放整本原文。每个任务完成后保存；再次选择同一 PDF 可直接复用，未完成任务仍可继续。

缓存配方包含转换流水线版本、模型、系统提示与格式指导摘要。配方变化时旧条目不命中；修改 PDF 提取逻辑或未纳入摘要的目标指导时须更新 pipeline 版本。缓存不会自动调用 AI 重新生成。

命中缓存、恢复进度与新草稿完成时，都会调用当前版本的本地 Host／Headless 预检：

- 重新解析内容包，检查单法术约束。
- 投影真实 Activity，检查来源绑定及 Activity schema。
- 使用机制注册表计算能力，而非信任 AI 的 full 标记。
- 列出兼容回退、手动阶段和模型声明的缺口。

预检不等同于完整自动化认证。返回状态只有 blocked 或 ready-for-behavior-tests；behaviorVerified 固定为 false。没有固定骰值的规则场景测试或玩家／DM 多端验收证据时，不产生“认证通过”结果。

缓存明确剔除旧 coverage、认证与验证字段；读取时核对记录摘要，恢复后重新预检，所以引擎更新不会沿用旧结论。摘要用于检测损坏，不是数字签名或信任授权。

“删除本批次缓存”删除该 PDF 当前配方的缓存和当前房间引用，不影响已安装内容。缓存不会上传服务器、市场或其他 DM；没有执行付费模型调用。
