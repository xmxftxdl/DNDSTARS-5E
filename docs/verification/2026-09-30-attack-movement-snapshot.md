# 紧接攻击前的直线移动

上一轮 Activity 父伤害记录有代码与测试进展。本轮重查全书审阅清单，定位骑兵移动→攻击诊断：原示例仅在移动后授予准备状态，不能凭该状态证明攻击紧接着所需直线移动。

新增通用 `movement-distance` 条件的 `basis:before-attack-straight-streak`。Host 按提交事件顺序把同回合连续自愿或合法骑乘直线移动快照写入紧接的第一次攻击；命中与失手均终止本次累计，下一次攻击不能借用。原生和 compiled 事务、registered Activity 提交均接入。原有 event/straight-streak 条件含义不变。该条件只提供攻击前距离；每回合次数、获得等级、豁免和结束清理仍由 Activity 明确配置。

模块导出重导入测试覆盖命中/豁免成功/失手、距离不足、转弯、未知直线路径、分段累计、跨回合骑乘/拖拽不继承、等级不足和回执重放。失手后原地第二击不触发，重新移动满足距离后再次命中可触发；DC17边界由目标自身投骰。两次攻击 Activity 仅第一击有移动快照，registered/compiled均验证。独立顺序测试验证同事务攻击后移动不能改变攻击前快照。非法非有限/负数上下文拒绝。
