# 投掷碰撞及同步命中后骰池

## 实现

投掷关联目标的碰撞伤害使用投掷者作为来源，实际有碰撞骰时加入修正，再归零和防御；无碰撞不领取，不把独立环境坠落骰加上攻击来源修正。

同步怪物 after-hit 机制通过内部回调沿用当前主攻击的领取记录，仅原攻击目标共享。主武器与多个额外伤害分量合计只领取一次，主攻击无骰则由首个有骰附加分量领取。其他目标使用其自己的来源效果。公共机制内部保留未归零原始总额；治疗和临时生命仍先归零，不追加伤害修正。
