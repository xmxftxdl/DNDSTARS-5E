# 持续区域的方向性移动耗费

## 本批实现

通用 create-persistent-area 新增 directionalMovementCost 声明，选择 area-orientation 和 additionalFeetPerFoot。Host 从已校验的矩形/立方区域选择保存单位风向；声明校验拒绝其他形状，持久化校验拒绝零向量、非单位向量、未知字段和无效耗费。后续来源 Token 移动不会改变既存风向。

寻路新增独立 additionalMovementCostPerFoot 回调。耗费为（困难地形倍率 + 方向性额外耗费）×独立速度耗费倍率；忽略困难地形不免除方向性耗费。同类环境费用取最高值。玩家/怪物移动、范围路径树、怪物规划、战斗模拟和受地图校验的自愿/反应移动均接入。水平点积反向时按格步目的位置的区域占用、目标资格与高度计算费用。

声明式字段、运行时提案、地图提交、存档迁移、导出重装和转换 SDK 说明对齐。没有修改任何原始 AI 生成草稿，也没有调用转换 API。

## 来源诊断与限制

守护之风的区域边界攻击劣势、操控风力下沉气流的区域攻击劣势、水墙的空间攻击劣势，已有明确共用接口与本地行为证据，可记录为当前运行时可表达；原始配置仍需集中重新转换及完整来源验收。不能从此推出整个法术通过。

操控风力的复合诊断仍保留部分解决：本批支持所选区域朝向对应的水平逆风格步费用；没有证明区域朝向之外任意独立风向的玩家选择、垂直逆风、连续空间积分、随动作切换/暂停/恢复、飞行条件豁免及上升气流摔落减伤。现有 PDF 范围描述的翻译歧义也不在本批解决。这些限制继续阻止整书最终认证。
