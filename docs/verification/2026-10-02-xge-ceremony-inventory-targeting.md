# 典礼术：物品选择传递及葬礼、圣水实际验收

## 缺口与修复

实际 v17 祝福圣水提交后被 Host 以 `item-resource-unavailable` 拒绝。失败 trace 的请求只有法术、职业、典礼选项和生物目标，未携带已选择的水瓶实例、持有者及库存版本；库存仍有水瓶，版本保持 2，排除了“物品不存在”的解释。地图选物品后的直接自施入口原本保留这些字段，但进入生物/区域目标草稿时丢失。

补齐 `Dnd5eSpellTargetingSession` 的三个选择字段，在插件目标草稿、单目标点击、猜测目标、自动区域提交及统一手动提交构造器中保留它们。请求仍只是选择意图；Host 继续验证目标持有者、版本、实例、原模板及原子材料结算，不在玩家端直接转换物品。
