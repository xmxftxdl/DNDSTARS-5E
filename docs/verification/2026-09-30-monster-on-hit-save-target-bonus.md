# 怪物命中后独立豁免伤害来源加值

## 实现范围

`resolveDnd5eMonsterOnHitEffects` 的 saving-throw-damage 是独立豁免伤害骰池。每个此类效果只给首个实际有骰的伤害分量加一次来源修正，再汇总做豁免减半或免伤，随后仍由原攻击公共结算应用防御。

主武器伤害与该独立豁免伤害分别领取一次；同一豁免伤害的多个伤害类型不重复领取。固定伤害分量被跳过，全固定伤害不领取。加值写入原骰修正后才归零。附带伤害保持非暴击骰数。能力值降低骰不属于伤害，未接入。
