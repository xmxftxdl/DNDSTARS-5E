# 原生攻击事件伤害类型与骰池衔接（2026-09-30）

## 实现

统一 emitDnd5eAttackResolved 可携带 Host 事务内骰池记录。普通武器入口沿用现有记录；重定向攻击与怪物武器攻击从实际主/额外/特性骰共享可变记录；玩家单次/连续法术攻击、怪物核心法术、延迟怪物机制攻击、武僧连击、接箭返击按已通过验证的实际伤害池保留记录。没有向客户端或存档开放记录字段。

上述事件同时提供实际父攻击伤害类型。以前多个入口没有该类型；本轮将声明式固定伤害继承能力连同事件支持一起补齐。子职校验现在允许 after-attack-hit、count=0、无缩放的固定伤害使用 parent-weapon，仍拒绝主动使用、没有 Host roll 的正骰池以及有缩放的伪固定池。

同一父事件可供多个附加能力共享记录；怪物、重定向入口保留原有加值先于防御、实际攻击者来源及多分量一次领取语义。独立豁免池不从父攻击借用领取状态。

## 剩余边界

commitDnd5eActivityExecution 的多检查/多 outcome 不能只按目标，把任意伤害提案的骰当成同一攻击池；需要继续核查可信的检查与伤害池连接，暂保留保守兼容，不宣称 full。
自动原生 after-hit 事件目前也不会为任意未预激活的有骰旧声明凭空生成 dice；本轮固定伤害支持不代表旧自动有骰声明全部可执行。不能靠 parent 类型字段放宽 Host roll 资格。
本轮对原生池记录的验证含现有伤害回归与新固定附加端到端；并未声称每个原生入口都能选择、收集并触发旧版有骰预激活能力。
