# 区域命令携带验收

新增 `movement.carryRestrainedTargets:true`。前一批已经给区域状态增加实例归属，本批通过共享规划器把同一区域当前有效的束缚目标随区域平移。旧状态没有实例归属时不推断；角色资料缺失时拒绝规划。

普通区域命令准备与提交两次校验，临时Headless快照包含未参加先攻的乘员；角色和NPC保持相对位置，位置、动作消耗、forced moved事件、空间关系与地图一起提交。Activity的relocate-granting-area使用同一规划器，交接路径和位移同步器显式接收carriedTargetIds。目标不花移动力、不因携带引发借机攻击；强制移动清除自愿直线移动距离。

## 后续：Activity 高度同步

携带提交审查发现 Activity 位移同步将省略高度的 Token 写成 0 尺，位移事件也直接用原始字段计算垂直距离。在抬高地形上会覆盖地图快照已经解析出的正确绝对高度。同步和事件现统一使用 mapGeometryTokenElevation，事件携带 fromElevationFeet/toElevationFeet。
