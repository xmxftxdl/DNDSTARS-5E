# SCAG 通用接口实施进度

本记录是分阶段实施状态，不是“四个法术已完整自动化”的验收报告。未打包扩展原文或官方美术。

## 已接入

- 触发范围 target.selection=choose-one：事件目标为中心，由 Host 计算候选，支持排除初始目标、视线和效果线检查。玩家可选择或跳过；伪造候选拒绝结算。地图端接入共享选择窗口。
- movement-property.movementKind：voluntary/forced/teleport。普通主动 move 的分类由 Host 写入；未分类旧事件不能满足具体分类条件。
- movement-source-distance：检查实际落点到位移来源的距离。
- 统一插件法术的地图位移成功后，按最终地图生成移动事件，向被移动者和位移来源分别开放后续 Activity。来源角色的后续定义保留来源的等级、目标关系及伤害归属。后续结算继续经过 Headless 和专注检查，不直接修改 HP。
- 高级 Activity 编辑器增加移动来源、事件中心及单个目标选择；内部 AI 结构化工具增加相应声明说明和拒绝错误替代的提示。

## 验证

6 个相关测试文件、74 项测试通过，包括实际落点与未发生位移的距离、后续来源角色、条件不满足不请求骰子、目标选择/取消/越界、旧事件不能伪装自愿移动。这里的 Host E2E 是程序测试，不代表实际浏览器双端完整施法验收。

## 尚未完成

1. 施法内嵌完整武器攻击：仍须复用现有装备攻击及中断流程，校验实际武器、材料价值、射程、重击、命中附效和一次动作消耗。不得用一个普通 attack-roll 或稍后可消费的攻击授权替代。
2. 轰雷类一次性延迟效果的完整生命周期、来源等级快照，以及细分移动/特殊受控移动的规则验收。
3. 四个法术逐一生成结构化定义、归档导入、房间分发和双端操作验收。当前只有通用原语的程序测试，不能将其称为四个法术的一键自动化已完成。
4. 位移后续当前接在统一插件法术路线；其他能力的地图交接尚需统一接入。一次原子交接同一生物多次位移只报告最终落点，不表示有可观察的中间提交。

转换工具仍须将施法内嵌武器攻击列入 unsupported；不能隐藏缺口或输出 full。
