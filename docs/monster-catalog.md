# SRD 5.1 怪物目录与 Headless 边界

## 数据来源

核心目录包含 334 只 SRD 5.1 怪物。`scripts/generate-srd-monsters.mjs` 从固定提交的英文转录生成
`src/rulesets/dnd5e/generated/srdMonsters.generated.json`，运行时不访问外部怪物 API。中文显示层只覆盖文字，
不得删除或改写已经结构化的规则字段。

更新命令：

```powershell
npm run generate:srd-monsters
```

## 当前自动化覆盖

- 普通武器攻击、由这些攻击组成的多重攻击、击中后的结构化击倒豁免。
- 亡灵坚韧、再生及其抑制伤害、群集半血伤害和不可恢复生命、充能动作。
- 传奇动作点、24 个结构化传奇武器动作、21 个传奇“侦测”检定。
- 20 个成年／远古巨龙的“翼击”：范围目标完整性、敏捷豁免、伤害、倒地和半速飞行移动额度均由 Host 验证。
- 怪物法术位和每日次数。128 个怪物法术中有 50 个也在核心 86 法术目录内；当前首批 11 个无区域、
  无专注且无复杂附带效果的法术使用 `monster-core-spell` 完整验证目标、距离、法术攻击／豁免、骰池、
  伤害／治疗和资源。其余法术明确走 DM 裁定，不标记为完整自动化。
- 吸血鬼真身、蝙蝠和雾形的结构化切换；月华之光豁免失败时会强制恢复真身。
- 房间怪物的巢穴动作事务入口：每轮一次、连续轮次不能重复同一效果，并记录权威战斗事件。
- 水下怪物攻击：无游泳速度的非例外近战武器具有劣势；水下远程攻击超过常规射程自动失手，
  弩、网及指定投掷武器按 SRD 例外处理。

## Fail-closed 边界

- 客户端不能把 `dm-adjudication` 动作伪装成普通武器攻击。
- 旧 `monster-spell` 裁定载荷不能用伤害法术治疗、用治疗法术造成伤害，或伪造不匹配的资源效果。
- `monster-core-spell` 只接受白名单法术。区域原点、持续效果、专注、召唤、传送和复杂命中附带语义未完成时，
  自动降级为 DM 裁定。
- 翼击必须提交范围内全部敌对生物的豁免；漏报目标、重复目标、错误骰数或越界骰值都会拒绝整项事务。
- 巢穴动作目前提供安全生命周期和事件入口；具体效果仍必须来自经 `monsterSchema` 校验的房间怪物定义。

## 仍未完整机械化

- 39 个与核心目录重合、但含区域、专注、持续状态或复杂附带效果的怪物法术。
- 78 个尚未进入核心 86 法术目录的怪物法术。
- 拟态怪、化形怪和魅魔／梦魔只改变外观、不改变数据的形态 UI。
- 传送、吞咽、擒抱、魅惑、墨汁云、召唤和多阶段变形。
- SRD 目录本身没有结构化巢穴动作数据；当前入口主要供房间怪物和后续规则包使用。
- 传奇动作中除武器攻击、侦测和龙翼击之外的特殊能力仍须逐项声明。

这些项目未完成前必须显示“DM 裁定”或“部分自动化”，不能仅因通过 Headless 事件记录就显示为“完整 Headless”。
