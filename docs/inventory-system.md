# SRD 5.1 物品栏与物品权威事务

## 数据边界

- `Dnd5eInventoryItemTemplate` 保存物品规则、图标语义、重量、价格、来源、使用动作和效果声明。
- `Dnd5eInventoryEntry` 是角色实际持有的物品实例，保存数量、获得时间、当前装备槽位和实例资源；实例同时保留模板快照，避免扩展规则暂时未加载时物品消失。
- 库存 schema V2 使用 `resources[]` 保存充能、次数等实例状态。资源的 `current` 归零只表示暂时耗尽，不会删除物品、减少数量或丢失模板快照；V1 的 `remainingCharges` 会在载入时迁移到对应实例资源。
- `short-rest` 资源会在短休或长休恢复，`long-rest` 资源在长休恢复；`dawn` 资源由 DM 权威战役时钟跨过每日 06:00 时自动恢复，休息按钮不再冒充黎明。
- `Character.dnd5eInventory` 随角色权威快照同步。旧角色首次迁移时会为当前武器、盾牌和护甲生成确定性实例。
- SRD 核心目录入口位于 `src/rulesets/dnd5e/items.ts`；魔法物品的独立目录、稀有度、类型、同调要求和自动化状态位于 `src/rulesets/dnd5e/magicItems.ts`。所有核心模板标明 `SRD 5.1 / CC BY 4.0`。
- Rules Plugin API V2 的 `registerItem` 可注册房间级自定义物品。Worker 只传出纯数据，Host 会校验模板 ID、文本长度、分类、图标、槽位、价格、重量、骰子、射程与全部效果数值。

## 权威流程

1. DM 分发直接执行 `grant` 事务并写入角色共享快照。
2. 玩家在非战斗界面进行装备、卸下、使用、丢弃或转交时，只发布包含实例 ID 与数量的请求；玩家不能提交治疗骰值或物品规则。
3. DM 端校验房间、角色所属成员、库存数量与转交目标，再执行事务。玩家通过 `characters` 资源失效通知取得结果。
4. 战斗中的 `dnd5e-item-use` 进入现有玩家行动队列。DM 端按当前库存模板重建效果、使用共享骰子盒掷治疗骰、检查动作／附赠动作、一次性提交角色 HP、库存、Token HP 和行动经济。
5. 滚珠、铁蒺藜与捕猎陷阱先进入地图选点：玩家只提交库存实例和目标格，DM 重建相邻范围、占格、库存与动作经济后，原子创建地图区域。
6. 角色或 SRD 怪物的移动路径进入区域时，由 DM 骰子盒掷敏捷豁免并调用 `item-area-trigger` Headless 动作。失败时分别处理倒地、1 点穿刺伤害与 10 尺速度减值、或 `1d4` 穿刺伤害与束缚；捕猎陷阱会停止在首次进入格并解除武装。
7. 玩家可以声明半速谨慎移动：每移动 1 尺消耗 2 尺移动，穿过滚珠或铁蒺藜时免除豁免。治疗至少 1 点生命值会由 Headless 清除铁蒺藜速度减值。
8. 强酸、炼金火焰与圣水已要求先选择 20 尺内生物目标；临时武器命中、持续燃烧与条件目标限制仍生成明确的 DM 裁定日志，不伪装成完整自动结算。
9. 插件装备可声明固定武器命中、武器伤害、AC、全部豁免和步行速度修正。Host 只汇总当前已装备物品，并把结果写入 Headless 角色快照；写在武器上的命中／伤害修正仅作用于该武器，不会串到另一只手。
10. 带 `attack-roll-reroll` 效果的已装备武器会在攻击骰公开后开启行动者中断。行动者可消耗该物品实例的 1 点充能，要求 DM Host 重掷指定攻击 d20；新结果必须采用，原骰、新骰和资源消费进入同一 `RollLedger`，只有攻击事务成功提交才扣除充能。

## 自定义装备包

“规则插件”页面提供“下载装备模板”。编辑 `.dndstars5e` 单文件中的 `api.registerItem({...})` 后，由 DM 上传到房间；玩家会按现有规则包握手自动下载、校验版本与 SHA-256 并激活。激活后，物品出现在 DM 分发列表中，来源会显示为插件名称。

当前白名单机械效果为 `weaponAttackBonus`、`weaponDamageBonus`、`armorClassBonus`、`savingThrowBonus`、`speedBonusFeet` 和消耗实例资源的 `attack-roll-reroll`。武器还可声明 5e 武器类别、近战／远程、伤害骰、伤害类型、攻击属性、触及、射程和属性文字；治疗物品可声明动作经济及治疗骰。未在白名单内的复杂效果应使用 `dm-adjudication`，不能在物品模板里注入页面 JavaScript。

## 当前核心模板

核心包含已接入自动攻击的武器、盾牌和护甲，以及背包、铺盖、麻绳、火把、火绒盒、水袋、口粮、医疗包、滚珠、铁蒺藜、捕猎陷阱、强酸、炼金火焰、圣水、抗毒剂、基础毒药和治疗药水。

魔法物品目录收录 SRD 5.1 的 240 个基础条目（含官方正文中的 `Shield, +1, +2, or +3` 与神器 `Orb of Dragonkind`），每条均可按中英文名称检索，并显示物品类型、稀有度、同调要求及自动化状态。复杂能力默认标为“DM 裁定”，不会仅凭规则文字修改角色或战斗状态。

首批完整 Headless 实例包括：基于当前 37 种基础武器生成的 +1～+3 武器、基于当前 3 种基础护甲生成的 +1～+3 护甲、+1～+3 盾牌，以及普通、强效、高效和极效治疗药水。武器命中／伤害、护甲／盾牌 AC 与治疗骰均复用既有权威事务，而非新增页面侧结算。

## 后续扩展边界

- 为捕猎陷阱补齐受困者“动作进行 DC 13 力量检定”及破坏链条事务；为强酸、炼金火焰和圣水补齐临时武器攻击及炼金火焰回合开始伤害。
- 为自定义装备扩展额外伤害骰、抗性、命中后状态、充能施法与条件式效果；这些字段需要逐项进入 Headless 事务和 Interrupt，不能只做 UI 文本。
- 增加容重、容器嵌套、货币、弹药、充能恢复日程和鉴定。
- 同调状态事务已实现：每名角色至多三件，先准备一件并在短休完成；职业／种族／阵营／施法者前置条件由 Host 校验，解除或转交会关闭相关效果。需要同调的装备在未同调时不会把数值或 Headless 效果投影到角色。
- 逐项将充能、施法、抗性、属性设值、召唤和特殊命中效果从“DM 裁定”升级为 Headless；每次升级必须同时更新模板的 `magicItem.automation` 标记和对应测试。
