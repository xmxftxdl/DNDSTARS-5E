# 生产包拆分与预算

## 当前策略

- 房间大厅、战役总览、地图、角色、法术书、通讯和设置均使用路由级懒加载。
- 房间共享资源协调器只在成功进入房间后加载；大厅不再提前初始化地图、怪物目录和地图几何。
- SRD 5.1 怪物正文目录保持为独立异步资源；轻量的伤害类型和房间怪物注册表不再反向依赖该目录。
- 3D 骰子继续使用独立 iframe 入口，不进入主应用入口包。

## 预算

`npm run build:check` 会执行生产构建并验证：

1. `main-*.js` 未压缩体积不超过 300 KiB。
2. 首页 HTML 不预加载地图页、SRD 怪物目录或 3D 骰子引擎。
3. 三类重型资源仍各自生成独立文件，防止被意外合并回入口。

2026-07-21 基线：优化前单一主包约 3,103 KiB；拆分后主入口约 210 KiB。地图页、怪物目录和骰子仍是较大的异步资源，后续 MapsPage 拆分应继续降低地图页资源，而不是放宽入口预算。
