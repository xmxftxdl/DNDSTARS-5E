# D&D 5e 2014 环境、移动与旅行

## 垂直移动

- 地图 Token 的 `elevationFeet` 是权威海拔。步行、攀爬、游泳、飞行和坠落都通过同一 `move` Headless 事务写回位置、海拔与剩余移动。
- 飞行必须具有明确的飞行速度；水平距离与上升高度都消耗移动，飞行速度与步行速度不同时按速度比例折算。没有飞行速度时，客户端预览和 DM 权威端都会拒绝飞行。
- 坠落仍按每 10 尺 `1d6`、最多 `20d6` 结算并在落地时倒地；受控下降不会误判为坠落。

## 水下战斗

- DM 可在地图几何工具栏把场景切换为“水下环境”。该设置随地图几何共享，不由玩家请求自报。
- 没有游泳速度时，大多数近战武器攻击具有劣势；匕首、标枪、短剑、矛和三叉戟例外。
- 远程武器超过常规射程会在掷骰前判定为自动失手；常规射程内仍具有劣势，弩、捕网以及按 SRD 列出的投掷武器例外。

## 魔法黑暗

- DM 先绘制一个障碍多边形，再将其勾选为“魔法黑暗”并记录法术环级。该区域会压制普通场景光源和 Token 光源。
- 普通黑暗视觉不能看穿魔法黑暗；盲视、真视以及 Token 上明确开启的“魔法黑暗视界”可以看穿。
- DM 端以半透明区域查看边界，玩家端显示不透明遮挡。服务端 Token 可见性过滤复用同一几何判定，避免只在画面上盖黑层却泄露隐藏 Token。

## 旅行

- 战役时间面板提供快速、正常和慢速三种旅行步调，分别使用 SRD 的每小时／每日里程。
- 困难地形将行进距离减半；快速步调对被动察觉施加 `-5`，慢速步调允许旅行中隐匿。
- 每日超过 8 小时会列出逐小时递增的强行军体质豁免（首个 DC 10，之后每小时 +1）。当前版本由 DM 确认掷骰和力竭，再推进权威战役时钟。
