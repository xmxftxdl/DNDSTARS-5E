# DNDSTARS-5E APP 全功能说明

> 文档基线：2026-07-24 当前工作区
> 规则基线：D&D 5e 2014／SRD 5.1（CC BY 4.0）
> 产品形态：浏览器 VTT、DM 权威 Headless 规则引擎、多人房间与可扩展规则平台

## 1. 产品定位

DNDSTARS-5E 是一套面向 D&D 5e 2014 跑团的中文虚拟桌面工具。它把房间、账号角色库、人物卡、地图、骰子、先攻、战斗结算、法术、物品、怪物、聊天、讲义、战役时间和规则插件放在同一个应用中。

平台核心采用以下原则：

- **规则版本固定**：核心规则只使用 D&D 5e 2014／SRD 5.1，不混入 2024 版 SRD 5.2.1。
- **DM 权威**：玩家提交行动意图，最终目标、距离、骰值、资源和结果由 DM Host 重新验证。
- **多端同步**：房间状态、骰子、战斗结果、日志、地图和规则包通过共享服务同步。
- **Headless 结算**：规则运算与 React 页面分离，行动通过权威事务进入规则引擎。
- **保守自动化**：没有安全机械化的内容会明确标为“DM 裁定”，不会根据说明文字猜测规则结果。
- **可扩展但不执行任意脚本**：自定义内容编译成 Host 白名单能力，不能直接访问页面和内部状态。

## 2. 功能状态说明

本文使用三种状态：

- **完整 Headless**：目标、资源、骰子和效果都能由权威规则事务自动结算。
- **部分自动化／DM Interrupt**：平台完成可验证部分，在关键节点等待 DM 或玩家选择。
- **DM 裁定**：平台可以正确消费行动与资源并记录日志，但具体叙事或复杂效果由 DM 决定。

“已经收录规则正文”不等于“已经完整 Headless”。法术、怪物能力和魔法物品会分别显示自己的自动化状态。

## 3. 用户角色与权限

| 身份 | 主要能力 | 明确限制 |
| --- | --- | --- |
| DM | 创建和管理房间、编辑地图、放置怪物、开始战斗、控制怪物、分发物品、导入内容、管理时间与场景 | 不能代替玩家执行玩家角色行动，也不能从角色页擅自编辑或删除玩家角色 |
| 玩家 | 创建和管理自己的角色、控制当前角色、移动、攻击、施法、使用物品、聊天和响应 Interrupt | 不能修改其他角色、敌方状态、DM 几何、房间规则或权威战斗结果 |
| 观战者 | 使用玩家安全视野查看地图和战斗 | 不占玩家名额；不能移动、掷骰、查看私密资料或修改房间状态 |

## 4. 房间大厅、账号与角色恢复

### 4.1 创建和加入房间

- 应用首先进入统一房间大厅，不再以端口决定 DM 或玩家身份。
- 创建房间的人自动成为 DM。
- 当前规则选择为 D&D 5e 2014／SRD 5.1。
- 玩家通过六位房间码或邀请链接加入。
- 服务端在最多八个玩家席位中自动分配空闲席位。
- 可选择普通玩家席位或只读观战席位。
- 加入前会显示房间名称、DM、在线状态、人数、密码要求、协议版本和规则包资料。
- DM 离线时禁止新玩家进入；原有成员可以在宽限期内重连。

### 4.2 房间管理

DM 可以：

- 复制邀请链接和房间码。
- 设置 1～8 人玩家容量。
- 锁定或解锁房间。
- 设置、修改或清除加入密码。
- 查看在线、暂时断线、主动离开和被移除的成员。
- 移除成员或恢复其加入资格。
- 在目标玩家在线且规则包就绪时转让 DM 权限。
- 查看最后在线时间、当前控制角色和规则包准备状态。

### 4.3 账号注册、登录与身份恢复

- 使用邮箱或手机号验证码完成注册，并设置用户名和密码。
- 用户名、已验证邮箱或已验证手机号均可用于密码登录。
- 登录后的设备会话可撤销；历史恢复码账号仍可由兼容接口迁移。
- 同一账号可以恢复原房间成员身份，而不是根据玩家同名进行匹配。
- 主动离开后可以重新加入；被 DM 移除后必须先恢复加入资格。
- 房间断线不会立即清除本地会话，页面重新可见或网络恢复时会主动重连。

### 4.4 账号角色库

- 角色归属于账号，不归属于房间席位。
- 玩家角色会保存到服务器侧账号角色库。
- 角色可以在不同房间之间携带。
- 带入房间前会检查规则集、角色 schema、最低游戏协议以及依赖插件的 ID、版本、状态 schema 和 SHA-256。
- 插件或版本不兼容时不会损坏角色，而是阻止将该角色带入当前房间。
- 当前角色库仍保存在共享服务器的文件目录中，不是独立公共云账号服务。

## 5. 战役总览

DM 的战役总览提供：

- 当前房间玩家与角色概览。
- 在线状态、规则包就绪状态和当前控制角色。
- 新建战役入口；新建战役会先关闭当前房间。
- 战役进阶数据。

当前进阶数据只展示玩家角色，不展示怪物数据，包含：

- 战役累计与单场战斗筛选。
- 角色有效伤害、承受伤害和治疗。
- 每回合平均伤害与每回合平均治疗。
- 临时生命值、减伤、击倒、击杀、救援和成功豁免等记录。
- 团队内相对进攻指数。
- 团队内相对防御／支援指数。
- 战斗中和非战斗中的 d20 点数分布。
- 战役经验值和战斗场次数。

进攻指数和防御／支援指数是应用内统计指标，不是 D&D 5e 规则数值。

## 6. 角色创建与人物卡

### 6.1 创建向导

角色创建支持两条流程：

#### 初出茅庐的冒险者

- 回答十个有关战斗方式、队伍定位、力量来源、玩法复杂度、魔法偏好、防御方式和非战斗能力的问题。
- 实时计算前三名职业倾向。
- 根据职业主属性、最终加点和种族调整推荐种族。
- 推荐阵营和背景。
- 在最终确认页显示推荐理由，而不是只给出结果。

#### 经验丰富的冒险者

- 先选择职业、种族、阵营和背景。
- 选择标准数组、27 点购点或 `4d6` 去最低值。
- 投骰结果逐项分配到六项属性。
- 最后加入种族属性调整。

### 6.2 起始装备

- 根据起始职业逐组选择 SRD 5.1 起始装备。
- 背景有核心起始装备时一并选择。
- 武器、护甲和盾牌可以在创建时直接装备。
- 已装备物品立即参与 AC、攻击和 Headless 结算。
- 其余物品进入角色库存。

### 6.3 人物卡字段

人物卡支持：

- 角色名称、玩家名称、种族、背景、阵营和经验值。
- 起始职业、总等级和各职业等级。
- 力量、敏捷、体质、智力、感知、魅力。
- 属性调整值、熟练加值、豁免熟练和技能熟练。
- AC、先攻、速度、被动察觉和感官。
- 当前生命、生命上限、临时生命和生命骰。
- 死亡豁免、状态和 ActiveEffect 只读投影。
- 激励骰数量。
- 背景故事和角色笔记。

技能按 2014 人物卡竖向归入默认属性；体质不显示不存在的默认关联技能。

### 6.4 立绘、先攻头像与地图 Token

“编辑立绘”统一管理：

- 人物卡完整立绘。
- 先攻栏使用的立绘裁切。
- 地图圆形 Token 的头像裁切。
- 玩家可以在完整立绘上拖动或缩放选择裁切范围，不需要重复上传三张图片。
- 角色、先攻栏和地图 Token 使用同一组角色图像资料。
- AI 生成按钮目前只是预留入口，尚未接入生成服务。

### 6.5 职业与兼职

- 支持 SRD 5.1 的 12 个基础职业。
- 职业进度覆盖 1～20 级特性、熟练、生命骰、职业资源和施法成长。
- 只显示实际获得新内容的等级，不用空白等级卡片占据页面。
- 核心子职只包含 SRD 5.1 允许收录的内容；其他子职必须由独立规则包提供。
- 支持兼职属性门槛、总等级熟练加值、各职业等级特性和有限的兼职熟练。
- 兼职不会错误重复授予起始豁免熟练或起始装备。
- 多职业施法会计算合并法术位和契约法术位。

### 6.6 角色页面权限

- 玩家只能创建、导入、导出和编辑自己的角色。
- 玩家可以选择当前控制角色。
- DM 角色页是只读房间名册。
- DM 可以打开已加入玩家的角色卡详情，但不能代替玩家改卡、回血、使用特性或删除角色。
- DM 可从名册发起全队长休，由权威时间和休息规则结算。

## 7. 职业资源、特性与休息

- 动作、附赠动作、反应和移动力按回合分别记录。
- 职业资源具有当前值、上限和短休／长休恢复方式。
- 职业特性根据职业、子职和等级自动授予。
- 需要选择的战斗风格、技能、法术、子职选项和高级特性会保存在角色上。
- 短休和长休会恢复相应职业资源、生命骰和法术位。
- 长休受战役时间的 24 小时限制。
- 角色降至 0 HP、昏迷、倒地、死亡豁免和稳定状态由 Headless 生命周期处理。
- 力竭、专注和标准状态可以跨回合同步并在休息或触发条件满足时解除。

## 8. 法术书

### 8.1 核心目录

- 收录 319 个 SRD 5.1 法术。
- 319 个法术均具有统一中文名称和基于英文 SRD 5.1 的中文正文。
- 支持按中文名、英文名和 ID 搜索。
- 支持按环级、职业、来源和自动化状态筛选。
- 法术详情显示学派、职业、施法时间、射程、成分、持续时间、仪式、专注、正文和升环效果。
- 界面明确标注“Headless”或“DM 裁定”。

### 8.2 角色法术管理

- 法师法术书按戏法、1 环到 9 环显示。
- 已准备法术在卡片右上角显示勾选标记。
- 未准备但已经抄入法术书的法术仍保留在对应环级。
- 其他施法职业按已知法术或准备法术规则管理。
- 戏法不占用法术位。
- 法术列表区和已学习／已知区域分开，便于查找。
- 点击法术卡片在屏幕中央打开完整详情。

### 8.3 房间法术导入

DM 可以：

- 下载 D&D 法术 JSON 模板。
- 导入自定义房间法术。
- 导出房间法术包。
- 移除已导入的房间法术。

房间导入法术可包含职业、环级、V／S／M、仪式、专注、持续时间、正文、升环和结构化机械声明。结构化字段本身不自动授予执行权限；只有通过 Host 白名单能力的法术才会进入自动战斗栏。

### 8.4 Headless 法术能力

当前核心审计记录 86 个完整 Headless 法术。现有通用施法链能够处理：

- 已知／准备法术资格。
- 动作、附赠动作和反应。
- 法术位、契约法术位与部分免位施法来源。
- V／S／M 成分。
- 法术攻击和目标豁免。
- 优势、劣势、暴击和掩护。
- 抗性、免疫、易伤和伤害类型。
- 升环伤害、治疗和目标数量。
- 专注开始、替换、检定和中断。
- 标准状态与 ActiveEffect 生命周期。
- 单体、多目标和地图范围模板。
- 持续区域、独立效果 Token 和移动区域。
- 反应法术与 Interrupt。

已接入的复杂示例包括火球术、睡眠术、油腻术、纠缠术、狂笑术、飞行术、变巨／缩小术、火焰刀、灵体武器、召雷术、月华之光、灵体卫士、荆棘丛生、炽焰法球、黑触手和火墙术等。

尚未完整机械化的法术仍可从地图法术栏发起“DM 裁定事务”。取消、超时、回合变化或复检失败时不会扣除动作或法术位。

## 9. 物品栏、装备与魔法物品

### 9.1 库存结构

- 物品分为装备、魔法物品、消耗品、冒险装备、工具和其他道具。
- 物品以图标卡片显示，悬停或点击可查看详情。
- 每个物品实例保存数量、装备槽、获得时间、来源和实例资源。
- 充能归零不会删除物品实例。
- 物品模板暂时缺失时仍保留实例快照，避免插件未加载导致物品消失。

### 9.2 玩家操作

玩家可以：

- 装备或卸下武器、护甲、盾牌和饰品。
- 使用已接入 Headless 的消耗品。
- 丢弃物品。
- 转交物品给同房间角色。
- 查看装备对 AC、速度、攻击和豁免的影响。
- 管理钱币、弹药、容器和同调状态。

战斗中只开放已经接入行动经济的物品使用；换装、丢弃和转交在角色页处理。

### 9.3 DM 分发与鉴定

- DM 可以从 SRD 5.1 或房间规则包选择物品并分发给玩家角色。
- 分发前显示中文正文、来源、稀有度、同调要求和自动化状态。
- 未鉴定魔法物品会对玩家隐藏名称、稀有度、正文和效果。
- DM 完成鉴定后才向玩家公开资料并允许使用、装备或同调。

### 9.4 物品规则

- 核心普通武器、护甲和盾牌接入攻击与 AC 结算。
- 武器类型、简易／军用、近战／远程、轻型、双手、灵巧、装填和射程进入熟练与攻击规则。
- 未熟练武器不加入熟练加值。
- 未熟练护甲／盾牌会施加相应检定、豁免、攻击和施法限制。
- 远程武器需要对应弹药；攻击事务成功结算后才扣除。
- 支持钱币重量、标准负重、可选负重、容器嵌套和超重限制。
- 支持最多三件同调物品以及短休完成同调。
- 支持短休、长休和黎明恢复的实例资源。
- 支持带充能的攻击骰重掷装备：公开攻击骰后开启 Interrupt，采用新结果后在同一事务扣除充能。

### 9.5 魔法物品目录

- 收录 240 个 SRD 5.1 魔法物品条目。
- 240 个条目均具有基于英文 SRD 5.1 的中文正文。
- 支持中英文名称检索、类型、稀有度、同调要求和自动化状态。
- `+1～+3` 武器、护甲、盾牌和治疗药水等已复用权威战斗事务。
- 复杂充能施法、召唤、属性设值或特殊命中效果在对应 capability 完成前保持 DM 裁定。

## 10. 地图与桌面工具

### 10.1 地图管理

- 上传地图图片并建立多张战役地图。
- 设定地图尺寸和网格大小。
- 显示或隐藏网格与坐标轴。
- 调整网格颜色、透明度和偏移。
- 自动分析底图是否自带网格，并允许手动校准。
- 地图支持缩放和平移。
- DM 可删除地图。

### 10.2 Token

- 放置玩家角色、SRD 怪物、自定义怪物和场景实体。
- Token 显示生命条、状态图标、飞行图标和当前回合闪烁。
- Token 名称默认隐藏，鼠标悬停时显示。
- 玩家人物卡立绘可以分别裁切为地图 Token 和先攻立绘。
- 怪物可以使用自定义 Token 与立绘。
- 先攻栏使用完整立绘风格，并在当前回合放大显示。

### 10.3 临时桌面协作

- 玩家双击地图产生 Ping 波纹。
- DM 可以把全体玩家视角聚焦到指定位置。
- DM 可以绘制临时箭头、圈选和标记。
- 临时标注与永久几何、迷雾和场景触发器分离。

## 11. 地图几何、视野与环境

### 11.1 墙、门和窗

DM 可以建立：

- 墙体及材质。
- 嵌入墙体并沿墙方向放置的门。
- 嵌入墙体的窗户。
- 障碍物与区域地形。
- 场景光源。
- 地面高度区域。

每个几何实体可以分别声明是否阻挡：

- 视线。
- 移动。
- 效果线。

门具有开启、关闭和上锁状态。门窗可以选中、编辑和删除；使用门窗工具时仍可从空白地图拖动平移。

### 11.2 掩护

- 根据墙、障碍物和生物占位计算半身、四分之三和全身掩护。
- 攻击前显示掩护预览。
- 远程攻击把掩护加入目标 AC 或敏捷豁免。
- DM 可以对单次攻击进行白名单覆盖并写入战斗日志。
- 障碍物可直接设置掩护等级和移动成本。

### 11.3 高度与三维路径

- DM 在战斗开始前通过拖动选择地图格并设置地面高度。
- 高度区域平时只显示外边界等高线，编辑时显示格子选区。
- Token 具有海拔和飞行状态。
- 移动路径按起点、路径节点和目标海拔进行三维距离与碰撞检查。
- 地面单位不能直接越过超过允许阈值的高度差。
- 飞行单位不会错误受到低于其飞行高度的地面困难地形影响。
- 视线、光源、墙高和目标海拔使用统一高度语义。
- 坠落、跳跃、攀爬和游泳进入通用移动规则。

当前地图仍是带高度规则的二维俯视 VTT，不是自由旋转的完整 3D 场景。

### 11.4 战争迷雾与动态视野

- DM 可以填充、清除和重新绘制迷雾。
- 支持矩形、笔刷和多边形显露／遮蔽。
- 玩家默认从自己控制的角色中心获得 30 尺视野。
- 墙、关闭的门、窗户、障碍物和高度会截断视野。
- 支持已探索区域记忆和当前可见区域。
- DM 可切换玩家视角预览。
- 玩家端不仅绘制黑色遮罩，服务端也会过滤当前不可见的隐藏 Token。

### 11.5 光照

- 支持明亮、昏暗和黑暗环境。
- 支持场景固定光源和 Token 携带光源。
- 光源具有明亮半径、微光半径、高度和启用状态。
- 墙、门和高度会阻挡光线。
- 支持魔法黑暗、普通黑暗视觉、盲视和真视等感官差异。
- 火把、提灯等光源可以随战役时间到期熄灭。
- 持续区域法术可以声明光照或魔法黑暗。

### 11.6 地图导入、导出与辅助识别

- 导出和导入地图几何 JSON。
- 导入 UVTT／DD2VTT 的网格、墙、门和光源。
- UVTT 带背景图时可直接创建新地图。
- 可以从地图图片识别候选墙线。
- 图片识别结果只是候选，必须由 DM 确认后才进入权威几何。
- 提供几何诊断、越界检查和修复入口。

## 12. 战斗系统

### 12.1 开始与结束战斗

- DM 从当前地图单位建立参战列表。
- 可以先设置突袭目标。
- 角色和怪物掷先攻并进入统一先攻栏。
- 先攻轮次、当前单位和回合数同步到所有客户端。
- 当前单位的先攻卡放大，地图 Token 周围显示动态回合提示。
- 队伍全部进入失败条件时可自动结束战斗。
- DM 也可以手动结束战斗。
- 玩家端在战斗结束事件到达后立即退出战斗界面，不等待 DM 完成经验分配。

### 12.2 战斗控制栏

玩家底部快捷栏按图标分组：

- 职业特性。
- 基础行动。
- 物品。
- 法术。
- 通用施法修正。

右侧提供自由骰盘与属性／技能鉴定：

- 选择 d4、d6、d8、d10、d12、d20 或 d100。
- 设置数量、调整值和标签。
- 勾选后作为角色属性／技能鉴定，由 Headless 重新计算角色调整值和 DC 结果。

### 12.3 基础行动

Headless 基础行动包括：

- 攻击。
- 施法。
- 疾走。
- 撤离。
- 闪避。
- 协助。
- 躲藏。
- 准备动作。
- 搜索。
- 使用物件。
- 擒抱与推撞。
- 借机攻击。
- 起身、唤醒和部分状态解除动作。

所有行动重新检查当前回合、行动经济、距离、视线、移动力和状态限制。

### 12.4 武器攻击

- 从实际装备的武器生成攻击。
- 检查武器熟练、使用属性、射程和弹药。
- 近战攻击距离不足时明确提示。
- 远程攻击处理正常射程、远距劣势、近身劣势和掩护。
- 支持优势／劣势、天然 20、重击、攻击重掷和伤害骰。
- 伤害经过临时生命、抗性、免疫、易伤和减伤顺序。
- 命中后特性在伤害提交前后进入相应 Interrupt 或触发事务。
- 移动离开敌人触及范围时处理借机攻击。

### 12.5 结算模式

当前只保留两种模式：

#### 自动结算

- 玩家行动和怪物行动都进入 DM Authority／Headless。
- 玩家仍由玩家本人选择和提交行动。
- 怪物由 DM 主机的确定性战术规划器行动。
- 怪物行动结束后自动推进回合。

#### 手动结算

- 玩家和 DM 可以使用公共骰盘。
- DM 可以明骰或暗骰。
- DM 手动应用伤害、治疗和临时生命。
- DM 在怪物回合移动当前怪物并选择攻击与目标。
- 玩家角色仍必须由玩家本人操作。
- DM 手动推进先攻。

无论哪种模式，DM 都可以随时对玩家或怪物进行战场修正：

- 调整当前生命、生命上限和临时生命。
- 添加、编辑或移除状态。
- 设置状态来源、持续时间和解除条件。

### 12.6 骰子与结果确认

- 使用 3D 骰子动画。
- 多枚同型骰会自动布局，避免重叠和异常倾斜。
- 明骰使用同一份预定骰值在所有客户端播放动画并写入日志。
- 暗骰只对 DM 显示。
- 骰值写入 `RollLedger`，记录原骰、重掷、修改来源和最终采用值。
- 如果失败结果存在可用奖励骰，系统才询问对应玩家是否使用；已经命中或无法改变结果时不重复询问。
- 如果敌方 d20 可能被某个玩家特性改变，系统才开启敌方骰结果 Interrupt。
- 没有任何符合资格的改骰特性时直接结算。
- DM 可以在暗骰确认中手动修改最终 d20，自动和手动模式均适用。

### 12.7 Interrupt 与 DM 裁定

Interrupt 用于在事务提交前暂停：

- 护盾术、法术反制等反应。
- 借机攻击和保护。
- 吟游诗人激励、锐评等改骰能力。
- 传奇抗性。
- 装备重掷。
- 插件选项。
- DM 裁定法术和持续区域调整。

Interrupt 具有唯一 ID、超时策略、单次消费和刷新恢复。等待期间会锁定原事务，避免多端重复扣资源或重复伤害。

### 12.8 状态效果生命周期

标准状态使用 `ActiveEffectInstance`，保存：

- 来源角色。
- 来源法术、特性、物品或怪物能力。
- 开始回合、剩余轮数和过期时点。
- 目标回合开始或结束时解除。
- 每回合重复豁免。
- 专注中断时自动解除。
- 受到伤害、攻击、移动或主动起身后解除。
- 状态免疫、重复状态和覆盖规则。

Token 右上角显示状态标记；点击后可查看来源与剩余时间。`conditions` 只是由 ActiveEffect 自动生成的只读投影。

### 12.9 战斗日志与表现

- 记录行动申请、命中、豁免、伤害、治疗、资源消费、状态、移动、Interrupt、拒绝原因和 DM 调整。
- 日志与共享骰子使用同一时间线。
- 战斗表现事件由 DM 发布并经 SSE 同步到玩家。
- 火球术支持从施法者飞向目标区域的小火球和范围爆炸动画。
- 持续区域可使用火焰、毒云、奥术等白名单视觉预设。
- Token 移动使用平滑动画，但最终位置仍以权威地图事务为准。

### 12.10 战斗经验

- 战斗开始时记录敌方怪物和 XP。
- 战斗结束后生成经验结算草稿。
- DM 可以平均分配或自由分配。
- 经验写入玩家角色并同步。
- 刷新、重连或重复点击不会二次发放同一场战斗经验。

## 13. 怪物目录、怪物工坊与战术 AI

### 13.1 SRD 怪物目录

- 收录 334 个 SRD 5.1 怪物。
- 334 个条目均具有统一中文资料。
- 数据包含六项属性、AC、HP、速度、豁免、技能、伤害防护、感官、语言、CR、XP、特性、动作、反应、传奇动作和施法资料。
- 支持中文名、英文名、CR、生物类型和能力标签搜索。
- 普通武器攻击和可安全组合的多重攻击进入 Headless。
- 复杂能力会明确标记 DM 裁定。

### 13.2 怪物工坊

DM 可以创建房间自定义怪物：

- 基础资料、体型、类型、阵营和 CR。
- 六项属性、AC、HP 和速度。
- 感官、技能、抗性、免疫、易伤和状态免疫。
- 特性、攻击和多重攻击。
- 攻击偏好、行为风格和 Headless 机制。
- 导入和导出 JSON。

自定义怪物经过 `monsterSchema` 校验后保存到房间，能够像 SRD 怪物一样放置、进入先攻和参加战斗。

### 13.3 目标偏好

DM 可以为怪物选择：

- 距离最近。
- 当前生命值最低。
- 生命百分比最低。
- AC 最低。
- 仇恨最高。

仇恨根据目标对怪物造成的有效伤害累积，DM 可以手动调整。

### 13.4 行为风格

确定性 Tactical Planner V3 支持：

- 均衡。
- 强攻。
- 守势。
- 游击。
- 惜命。

规划器会在 Host 已经生成的合法方案中比较：

- 原地攻击。
- 移动后攻击。
- 撤退后攻击。
- 寻找半身或四分之三掩护。
- 疾走。
- 闪避。
- 借机攻击风险。
- 期望伤害、命中率、击倒机会和理想距离。
- 哥布林等怪物的灵巧脱逃。
- 飞行单位的三维移动。
- 同时比较全部存活合法目标；DM 目标偏好是强指令，目标不可执行时安全回退。
- 目标生命比例、专注、仇恨、相邻支援、生存风险、控制/辅助收益和有限资源成本。

当前默认不是生成式 AI。`MonsterDecisionProvider` 已把合法方案生成和评分器分离，未来可以接入受限本地模型，但模型只能给合法候选方案评分，不能直接移动 Token、修改 HP 或绕过 Headless。

### 13.5 遭遇模拟器

DM 可以在战役总览选择当前角色和 SRD 5.1 怪物，使用固定随机种子批量模拟 1–1000 场。模拟器复用 Tactical Planner V3 的候选评分，并统计玩家/怪物胜率、95% 胜率区间、平均轮数、存活单位、平均伤害与剩余生命值。

模拟器会显示自动化覆盖率。当前纳入角色武器攻击、怪物武器/多重攻击、射程与劣势、伤害抗性/免疫/易伤、再生、充能和每日次数；地图墙体、精确掩护、法术选择、传奇/巢穴动作、反应、专注、死亡豁免和 DM 裁定能力不会被伪装为已模拟。模拟结果只用于遭遇强度预估，不会写回房间或替代真实 Headless 战斗。

### 13.6 怪物机制编辑器

机制声明可以配置：

- 回合开始。
- 命中后。
- 受到伤害后。
- 阶段转换。
- 生命百分比阈值。
- 每回合一次、每场一次或无限制。
- 治疗、临时生命、伤害和标准状态。
- 召唤和范围攻击的部分声明。

只有当前安全闭环完整的组合会标为完整自动化。需要落点、范围方向或跨事务来源的能力会降级为部分自动化或 DM 裁定。

## 14. 群体检定

DM 可以发起全队检定：

- 选择属性或技能。
- 设置 DC 和掷骰方式。
- 选择参与角色。
- 所有玩家端同时收到掷骰提示。
- 服务端验证角色身份和结果。
- DM 汇总查看成功、失败、总值和被动值兜底。
- 结果可以进入战役统计与共享日志。

## 15. 通讯、讲义与日志

### 15.1 文字聊天

- IC 角色内频道。
- OOC 角色外频道。
- 玩家与 DM 的私密纸条。
- DM 可以选择地图上的 NPC Token 作为发言身份。
- `/roll 2d6+3` 等行内骰式由房间服务端掷骰。
- 公共频道骰点同时进入战斗日志时间线。

私聊和私密讲义经过服务端投影，不会只靠前端隐藏。

### 15.2 讲义

- DM 可以创建文字讲义。
- 可以附加图片。
- 可以分发给全体玩家或指定玩家。
- 也可以保存为只有 DM 可见的草稿。
- 玩家收到未读提醒。
- 讲义可以绑定到地图场景和触发区域。

### 15.3 战役日志

- DM 手动记录剧情日志。
- 战斗结束可以生成战斗摘要。
- 日志包含标题、正文、作者和时间。
- 场景触发器可以自动写入日志。

### 15.4 队伍共享手记

- 支持任务、线索和普通笔记。
- 可以填写标题和正文。
- 队伍成员可以更新。
- 任务可标记完成或重新打开。

## 16. 战役时间、休息与旅行

### 16.1 战役时间

- 可以使用“战役第 N 日＋时刻”。
- 也可以手动输入现实历法日期，例如 1992 年 10 月 10 日。
- DM 可以按分钟、小时或天推进时间。
- 时间变化同步到全房间。

### 16.2 时间驱动效果

- 长休推进八小时。
- 24 小时内重复长休不会再次获得完整长休收益。
- 黎明恢复资源在战役时间跨过每日 06:00 时恢复。
- 火把、提灯等光源按燃烧时长熄灭。
- 非战斗专注和分钟级法术可以到期提醒。
- DM 可以建立与角色关联或不关联的计时提醒。

### 16.3 旅行

- 支持快速、正常和慢速旅行步调。
- 计算每小时和每日行程。
- 困难地形降低行进距离。
- 快速步调降低被动察觉。
- 慢速步调允许旅行中隐藏。
- 每日超过八小时会生成逐小时提高 DC 的强行军体质豁免。
- 当前强行军结果与力竭仍由 DM 确认后推进。

## 17. 场景编排与地图互动

### 17.1 场景

一张地图可以升级为一个可运行场景，并绑定：

- 预设遭遇。
- 讲义和战役日志。
- 环境光与迷雾。
- 背景音乐或环境音。
- 地图互动点。
- 圆形或矩形触发区域。

### 17.2 触发器

Token 进入或离开触发区域时，可以按顺序执行：

- 展示讲义。
- 向触发玩家发送密语。
- 发起群体属性／技能检定。
- 改变门的开启、关闭或上锁状态。
- 改变环境光。
- 填充或清除迷雾。
- 投放预设遭遇并可立即开始先攻。
- 播放或停止同步音频。
- 传送 Token 到另一张地图或楼层。
- 写入任务。
- 写入战役日志。

### 17.3 DM 控制

- 预览动作序列。
- 暂停场景自动执行。
- 单步执行队列中的一个动作。
- 修正失败动作后继续。
- 丢弃当前待执行队列。
- 对可逆的门、光照、未开始战斗的遭遇和传送执行撤销。
- 重置“一次性触发”记录。

已经向玩家展示讲义、发送密语、完成检定或开始战斗的外部结果不会伪造撤销。

### 17.4 地图互动点

DM 可以在战斗开始前放置书柜、宝箱、机关等互动点：

- 设置互动距离。
- 设置属性或技能检定和 DC。
- 设置成功、失败或自动成功结果。
- 检定成功后直接把物品写入执行角色的库存。
- 玩家只看到可互动对象，不会收到隐藏 DC 和奖励配置。
- 距离、角色归属、检定和奖励都由 DM Host 复核。

后续可以在同一声明式结构上扩展金币、任务推进、陷阱伤害和状态效果。

## 18. 场景音频

- DM 可以导入 MP3、OGG、WAV、M4A、AAC 和 WebM 音频。
- 音频可标记为音乐、环境音或音效。
- 场景可以绑定背景音频。
- 支持播放、暂停、继续、停止、循环和统一房间音量。
- 播放状态带服务器时间戳。
- 客户端通过服务器时间校正播放位置。
- 刷新、重新加入和设备时钟不同不会让音轨从头开始。
- 浏览器阻止自动播放时会提示玩家手动启用一次。

## 19. 规则插件与自定义内容

### 19.1 房间规则包

- 核心包只包含 SRD 5.1。
- DM 可以上传自己有权使用和分发的规则包。
- 加入房间时显示插件名称、版本、发布者、许可证和哈希。
- 玩家自动下载、验证并激活 DM 固定的精确版本。
- 插件文件按房间隔离，不进入公共索引。
- DM 升级插件时使用暂存、状态迁移预检和 CAS 原子激活。
- 迁移失败、版本冲突或哈希不符时继续保留旧版本。

### 19.2 安全沙箱

- 插件在隔离 Worker／WASM 沙箱运行。
- 禁止访问 DOM、`window`、网络、WebSocket、localStorage、IndexedDB、Cache 和内部 Store。
- 禁止动态代码构造、任意 `eval` 和任意页面 JavaScript。
- 插件只能返回可序列化声明和调用 Host 白名单 capability。
- Host 重新验证角色资格、目标、距离、阵营、骰子、资源、行动经济和 transaction ID。
- 非法字段、负数资源、重复事务和超量操作会被拒绝。
- 不支持的能力必须降级为部分自动化或 DM 裁定。

### 19.3 DM 规则包工作室

无需手写代码即可创建：

- 子职。
- 等级特性。
- 子职资源。
- 通用特性。
- 种族。
- 背景。
- 属性生成方式。
- 法术。
- 武器、护甲、饰品、治疗物品和一般道具。

工作室支持：

- 保存和载入当前浏览器草稿。
- 下载 `.dndstars5e` 插件文件。
- 上传、启用并发布到当前房间。
- 高级 JSON 编辑。
- 实时 schema 错误。
- 自动化兼容报告。

兼容报告会显示完整自动化、部分自动化和手动裁定数量，并列出不能完整自动化的原因。

### 19.4 声明式子职能力

`DeclarativeSubclassAbilityV1` 可以声明：

- 主动、命中后、受伤前后、回合开始／结束和休息完成等触发器。
- 职业、子职、等级、装备、距离、关系、状态和资源条件。
- 动作、附赠动作、反应、移动、资源和使用次数。
- 自身、单体、多目标和范围目标。
- 攻击、豁免、伤害、治疗和数值缩放。
- 伤害、治疗、临时生命、标准状态、移动和资源变化。
- 每回合、短休、长休和公式次数限制。
- 固定轮数、回合边界、专注和永久持续时间。
- 是否能够改变敌方 d20 结果。
- `full`、`partial` 或 `manual` 自动化等级。

加载规则包后会自动完成子职、特性、资源、按钮和 Headless Action 注册，不需要为每个子职编写新的 React 页面。

### 19.5 效果编辑器当前边界

特性效果编辑器支持：

- 动作经济。
- 自身、单体和圆形／锥形／线形／矩形范围。
- 伤害、治疗和临时生命。
- 标准状态与持续时间。
- Interrupt。
- 持续区域触发器。
- 单体 SRD 召唤。

法术效果编辑器支持：

- 法术位、成分、命中／豁免、伤害、治疗、升环、状态和专注事务。
- 当前安全自动化重点是自身或单一目标；复杂多飞弹、昂贵材料和部分范围语义会降级。

装备效果编辑器当前完整纵向切片为：

- 物品实例充能。
- 攻击骰公开后重掷一枚 d20。
- 资源与骰子在同一事务原子提交。

## 20. 多端同步、存档与恢复

### 20.1 共享协议

- 共享状态使用协议 v3。
- 每个资源带 schemaVersion、revision、writerId 和 writtenAt。
- 写入使用 expected revision／CAS。
- 同一资源的本地连续写入会排队。
- 冲突写入返回 409 并重新读取权威状态。
- 删除写入带 revision 的 tombstone，旧客户端不能复活已删除资源。
- SSE 事件带房间序号和服务器实例 ID。
- 客户端忽略重复事件，并在检测到断档或服务器重启时执行全量恢复。

### 20.2 权威提交

- 玩家行动带 combatId、round、initiativeIndex、sequence 和 actionId。
- DM 预检错误战斗、错误回合、错误角色和重复 action。
- `CombatTransaction` 负责行动资源、骰子、效果和提交阶段。
- `RollLedger` 保存所有采用骰和修改来源。
- `InterruptWindow` 在资源提交前暂停。
- 角色、Token、地图区域、行动经济、ACK 和日志尽量一次性提交。
- 过期客户端不能凭较新的本机墙钟覆盖服务器 revision。

### 20.3 战役安全

- 服务端在共享状态改动前按节流策略自动建立快照。
- 每个房间轮转保留最近恢复点。
- DM 可以手动创建快照。
- 还原前自动建立保护快照。
- 可以导出完整战役包。
- 导入前显示状态、图片和插件预检结果。
- 完整战役包包含共享状态、地图图片、规则元数据和房间托管插件。
- 损坏 JSON 会 fail closed，并移动到隔离目录，不覆盖最后一份正常状态。

### 20.4 错误与诊断

- 应用外壳和每个主要路由都有独立 Error Boundary。
- 单页异常不会让整个 DM 或玩家端白屏。
- 提供服务器协议与构建版本兼容提示。
- 提供共享数据完整性提示。
- 提供同步冲突、重复事件、事件断档和 revision 诊断。
- 提供 ActiveEffect 状态诊断。
- 提供地图几何诊断。

房间管理、战役恢复和高级诊断集中在“设置”页，不占据日常跑团界面。

## 21. 典型跑团流程

1. DM 使用邮箱或手机号注册并登录账号。
2. DM 创建房间，选择 SRD 5.1，并按需要上传规则包。
3. DM 复制邀请链接。
4. 玩家注册或登录账号并加入房间。
5. 玩家创建角色，选择起始装备和法术。
6. 系统检查角色与房间规则包兼容性。
7. DM 上传地图，校准网格，绘制墙、门、窗、光源、高度和迷雾。
8. DM 放置角色、怪物、互动点和场景触发器。
9. DM 开始战斗并设置突袭与结算模式。
10. 玩家从底部快捷栏移动、攻击、施法、使用物品和特性。
11. DM Host 校验并执行 Headless；需要时开启 Interrupt 或 DM 裁定。
12. 战斗结果、骰子、动画、状态和日志同步到所有客户端。
13. 战斗结束后玩家立即退出战斗状态，DM 再分配经验。
14. DM 写入日志、推进战役时间并创建或导出恢复点。

## 22. 当前明确边界

以下内容不应被误认为已经完整完成：

- 账号角色库目前依赖单台共享服务器，不是独立公共云服务。
- 当前网络服务适合封闭测试，公开部署前仍需完成生产鉴权、TLS、安全响应头、备份与监控。
- 不是所有 319 个法术都已 Headless；当前核心审计为 86 个。
- 不是所有 334 个怪物的传奇动作、巢穴动作、施法、变形、再生、群集和充能能力都已机械化。
- 不是所有 240 个魔法物品都已自动结算。
- 地图具有高度和三维路径规则，但渲染仍以二维俯视地图为主。
- AI 立绘生成尚未实现。
- 怪物默认使用确定性战术评分，不使用生成式本地 AI。
- 应用目前不提供内置语音或视频通话。
- 自定义规则包不能绕过沙箱执行任意代码。
