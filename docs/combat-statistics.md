# Headless 战斗统计 V1

战斗统计由 DM 端订阅成功完成的 D&D 5e Headless 事务生成。它不解析战斗日志文本，也不接受玩家端直接上报的伤害或贡献值。

## 统计口径

- 输出与承伤按目标实际损失的生命值和临时生命值计算；过量伤害不计入输出。
- 治疗只记录实际恢复量。把其他单位从 0 HP 恢复到正数时，治疗者同时获得一次“救援”。
- 控制记录对敌对单位成功施加的标准状态，以及驱散亡灵等结构化控制事件。
- 击倒记录目标从正生命降至 0 HP；没有死亡豁免且没有待结算亡灵坚韧的目标同时记为击杀。
- 另行记录攻击、命中、重击、豁免、专注检定、减伤、行动/附赠动作/反应、移动、职业资源和法术位消耗。
- 手动结算不会伪装成 Headless 事件，因此 V1 不把 DM 直接修改的 HP 归给任何角色。

“贡献值”仅用于快速复盘：输出、治疗、临时生命、减伤按实际数值计入；控制每次 5 分，击杀与救援每次 10 分。它不是 D&D 5e 规则数值，也不能替代 DM 对战术、探索和叙事贡献的判断。

## 权威、同步与恢复

- Headless 结算观察器只在根事务结束后触发一次，不改变结算结果；统计代码抛错也不会让战斗事务失败。
- 每次事务生成确定性 receipt；同一输入状态、动作和事件被重放时不会重复计数。
- `combat-statistics` 是 DM 写入的房间共享资源，客户端与服务端都执行严格 schema 校验，损坏数据会 fail closed。
- 房间保留最近 24 场战斗，每场最多保留 4096 个 receipt；DM 可以在地图左下角打开或重置当前场次。
