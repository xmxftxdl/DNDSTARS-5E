# D&D 5e 状态效果生命周期 V2

本层以 D&D 5e 2014 / SRD 5.1 为规则基线，并继续遵守 DM 权威与 Headless 结算边界。

## 权威数据

角色与未关联角色的 Token 都把状态实例保存到：

```text
dnd5eCombatState.activeEffects: ActiveEffectInstance[]
```

每个实例包含稳定 ID、状态定义 ID、来源角色、来源法术或特性、持续方式、重复豁免、事件解除条件、叠加策略、可见性及受限的 Headless modifier。当前核心 modifier 支持速度加值、速度减值、禁止反应与指定伤害类型抗性；规则插件只能通过公开 capability 创建声明式实例，不能注入任意结算代码。

`conditions: string[]` 只保留为 `activeEffects` 自动生成的只读投影，供现有规则查询与旧界面显示。角色卡不能直接编辑它；DM、法术、职业特性、怪物能力及插件都必须通过统一 ActiveEffect 工厂和 Headless 事务写入。

旧字符串状态与 `timedEffects` 会在角色存档、地图存档、共享资源或 Headless 快照入口一次性迁移。迁移 ID 与时间戳是确定性的，因此 DM、玩家端和断线重连客户端不会各自产生不同实例。迁移完成后旧字段会被移除，速度降低、禁止反应、持续轮数和重复豁免全部由原生 ActiveEffect 生命周期推进，不再双写或双计时。

角色存档版本为 23，地图存档版本为 3；持久化战斗状态使用 `dnd5eCombatState.schemaVersion = 2`。本地旧存档可以迁移，但共享资源中的损坏 v2 实例、重复 ID、非法持续时间、旧 `timedEffects` 或伪造的 `conditions` 投影会 fail closed，并进入既有隔离/完整性提示流程。

## 生命周期

Headless 当前统一处理：

- 固定轮数，在目标回合开始或结束时扣减；
- 来源或目标的回合开始 / 结束边界；
- 目标回合开始或结束的重复豁免；
- 来源失去专注、施放新专注法术、昏迷或生命值降到 0 后解除；
- 受到伤害、成为攻击目标、被命中、发动攻击或移动后解除；
- 标准状态免疫；
- 拒绝重复、刷新持续时间、替换、保留更强效果和允许叠加。

重复豁免所需骰子在结束回合事务中一并准备。目标回合结束的豁免在当前生物结束回合时处理；下一个生物回合开始的豁免也由同一 DM 权威事务预先掷骰并结算，避免客户端自行随机。

## DM 界面

自动和手动结算模式下，DM 状态编辑器均可设置：

- 来源角色与来源法术 / 特性名称；
- 永久、固定轮数、指定回合边界或专注持续；
- 重复豁免的属性、DC 与结算时点；
- 伤害、攻击、命中、发动攻击和移动解除；
- 重复与覆盖策略。

Token 右上角的标准状态标记可以点击。详情弹窗固定在浏览器视口中央，显示每条实例的来源、剩余轮数、专注、豁免和自动解除条件。

DM 仪表盘新增“D&D 5e 状态数据诊断”，检查旧字段、schema 版本、损坏实例、投影不一致、悬空来源与失效专注引用。安全的旧格式可以一键迁移并重建投影；损坏实例不会被自动删除，必须从快照恢复或由 DM 明确处理。

## 同步与恢复

状态实例随既有 `characters` 和 `maps` 房间资源同步，不创建旁路通道。DM 保存的角色战斗状态在玩家端合并时属于权威字段；玩家的陈旧本地状态不能覆盖它。未关联怪物 Token 的 `dnd5eCombatState` 同样由 DM 快照覆盖。

因此重连流程只需要恢复最新房间资源；再次建立 Headless 快照会验证和补齐旧迁移，不会重置剩余轮数，也不会生成新的旧状态 ID。
