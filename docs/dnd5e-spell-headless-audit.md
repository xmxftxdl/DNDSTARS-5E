# SRD 5.1 法术 Headless 接入审计

审计范围：`spellCatalog.ts` 中 319 个 SRD 5.1 法术，以及 `DND5E_SRD_COMBAT_SPELLS`、地图施法准备层和 DM Authority／Headless resolver。

“已收录中文正文”“人物卡可以学习”和“已接入 Headless”是三个独立状态。只有同时具备地图交互、权威校验、资源／行动经济消费、效果结算和多端 ACK 的法术才能标记为 Headless。

## 当前已接入：55 个

- 戏法：维生术、酸液飞溅、火焰箭、冷冻射线、电爪、冻寒之触、魔能爆、燃火术、毒气喷溅、圣火术、恶言相加。
- 一环：妖火、虚假生命、曳光弹、炼狱叱喝、猎人印记、疗伤术、治愈真言、灾祸术、祝福术、虔诚护盾、致伤术、魔法飞弹、护盾术、燃烧之手、雷鸣波。
- 二环：隐形术、树肤术、防护毒素、目盲／耳聋术、人类定身术、次级复原术、灼热射线、粉碎音波。
- 三环：群体治愈真言、法术反制、火球术、闪电束。
- 四环：高等隐形术、防死结界、放逐术、枯萎术。
- 五环：怪物定身术、群体疗伤术、寒冰锥。
- 六环：医疗术、死亡法阵、连锁闪电、解离术、冰封法球（立即发射模式）。
- 七环：死亡一指。
- 八环：律令震慑、阳炎爆。
- 九环：群体医疗术、律令死亡。

其中死亡一指造成的伤害已结算，但人形生物死亡后的僵尸生成仍由 DM 裁定。燃烧之手、雷鸣波、粉碎音波、火球术、闪电束、死亡法阵、寒冰锥、冰封法球与阳炎爆已有锥形／立方体／球形／直线地图模板；选中法术时显示尺寸和高亮格，点击地图会自动框选范围内 Token。DM Authority 仍会复核射程、最大目标数和连锁目标关系。

所有短期与持续状态统一使用可持久化 `ActiveEffectInstance`：效果会随角色或未关联怪物 Token 同步，且只能由 Headless 在施法者／目标回合边界或声明的中断触发点推进。冷冻射线实际限制移动与疾走；电爪会检查金属护甲优势并封锁反应；阳炎爆对亡灵／泥怪施加豁免劣势并结算重复豁免。妖火会压制隐形收益，普通隐形术在攻击或施法时只解除对应目标，最后一个目标解除时同步结束专注；树肤术、防护毒素与防死结界分别接入 AC 下限、毒素抗性和死亡拦截。自动怪物和手动怪物推进走同一权威事务。

## 第一批：可复用现有结算模型（已完成）

群体治愈真言和群体疗伤术均已复用多目标治疗、升环、生命领域加值与亡灵／构装体排除。群体疗伤术额外使用 DM 权威重建的 30 尺球形模板，并允许施法者选择自己。

## 第二批：需要一个短期状态或特殊数值规则

这些法术可以沿用现有攻击、豁免、伤害、治疗、条件和回合钩子，但必须完整实现附带效果，不能只结算伤害后就标记为完成。

| 法术 | 需要增加的规则 |
| --- | --- |
| 曳光弹 | 命中后，对目标的下一次攻击具有优势，并在施法者下一回合结束前过期 |
| 强酸箭 | 未命中仍承受初始伤害一半；命中后在目标下一回合结束时结算后续强酸伤害 |
| 医疗术 | 固定数值升环治疗；移除目盲、耳聋和疾病；亡灵／构装体无效 |
| 重伤术 | 伤害不能令 HP 低于 1；失败时等量降低生命上限并持续一小时 |
| 律令震慑 | 150 HP 门槛、震慑状态，以及目标每回合结束时的体质豁免 |

## 暂不应直接标记 Headless 的类型

- 持续区域底座已经支持权威地图实体、首次创建／进入／回合开始／回合结束触发、每轮去重、豁免、伤害、状态、移动路径检测、专注清理和 DM 中断；各法术仍需逐项声明其具体触发模板。
- 召唤与独立实体底座已支持单体 SRD 5.1 生物：带所有者、DM 操作、独立先攻、阵营、持续时间、专注解除、0 HP 离场和多端同步。灵体武器、多只生物共享先攻、玩家移交控制和各具体召唤法术的选择限制仍需逐项接入。
- 复杂控制：命令术、睡眠术、人类定身术、目盲／耳聋术等，需要标准化条件语义、重复豁免、自动回合行为或 HP 池分配。
- 施法打断：法术反制、解除魔法等，需要在被反制法术消费资源和提交结果前暂停原事务，并支持反制嵌套。
- 地形、传送与立体移动：迷踪步、飞行术、任意门、墙类法术等，需要合法落点、视线、碰撞、区域和高度模型。
- 纯探索／叙事法术：侦测魔法、鉴定术、预言类和多数幻术。它们可以保留结构化规则与 DM 裁定，不必为了提高 Headless 数量而伪造自动结算。

## DM 裁定与自动战斗中断边界

未机械化但已被角色学习／准备的动作与附赠动作法术现已进入地图法术栏，并通过 `dnd5e-adjudicated-spell`＋`dm-adjudication` 事务处理。玩家请求不会立即扣资源；DM 可填写最终伤害、治疗、临时 HP、状态增删、专注轮数与备注，批准后才由 Headless 原子消费动作和法术位并应用结果。取消、十分钟超时、回合变化或最终复检失败均不消费。反应法术仍不开放普通按钮，必须等待对应触发器接入。

自动结算事务仍不允许 DM 在 resolver 已完成后静默修改结果。首版 DM 专用 `dm-adjudication` Interrupt 已按以下边界实现：

1. DM Authority 完成 preflight 和骰值准备，但不提交 Headless 结果。
2. 生成包含事务 ID、行动、目标、骰值、DC 和拟应用结果的 DM-only interrupt。
3. DM 选择“批准并提交／取消施法”，修改项只能使用白名单字段。
4. Authority 应用经过 Headless 校验的裁定 action；不得直接写内部 Store。
5. 一次性提交角色、Token、行动经济、资源、ACK 和战斗日志。DM 修改必须在所有客户端的日志中可见。
6. Interrupt 具备超时默认分支、幂等 ID 和单次消费；插件只能请求该 capability，不能自行批准或写共享状态。

首版已开放：最终伤害、治疗、临时 HP、目标排除（不添加该目标效果）、附加／移除条件、专注持续轮数、裁定备注和通用持续区域。检定 DC 临时修正与更多反应法术仍需逐项接入；任意脚本、任意 Store patch、跳过 DM 身份验证或结算后无日志改血都不开放。
