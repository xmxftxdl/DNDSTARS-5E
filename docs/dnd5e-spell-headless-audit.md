# SRD 5.1 法术 Headless 接入审计

审计范围：`spellCatalog.ts` 中 319 个 SRD 5.1 法术，以及 `DND5E_SRD_COMBAT_SPELLS`、地图施法准备层和 DM Authority／Headless resolver。

“已收录中文正文”“人物卡可以学习”和“已接入 Headless”是三个独立状态。只有同时具备地图交互、权威校验、资源／行动经济消费、效果结算和多端 ACK 的法术才能标记为 Headless。

## 当前已接入：84 个

本批新增黑触手、火墙术、魅影杀手与飞行术。黑触手使用 20 尺方形困难地形，处理首次进入／回合开始的敏捷豁免、3d6 钝击伤害、同源束缚，以及力量或敏捷检定挣脱；已被同一片黑触手束缚的生物在其中开始回合时不再重复豁免，直接承受伤害。魅影杀手会建立专注恐慌效果，并在目标每个回合结束时进行感知豁免：失败结算 4d10 心灵伤害（升环每环 +1d10），成功原子结束目标效果与对应专注。火墙术当前完整支持直线墙：出现时墙内目标敏捷豁免、成功伤害减半；进入墙体或在施法者选定的 10 尺伤害侧结束回合时无豁免受伤，升环每环 +1d8。飞行术以专注 ActiveEffect 授予 60 尺飞行速度，并复用地图三维路径、海拔和移动力权威校验。环形火墙、20 尺高度与不透明视线阻挡尚未进入权威三维区域模型，因此仍明确降级为 DM 裁定，未静默模拟。

- 戏法：维生术、酸液飞溅、火焰箭、冷冻射线、电爪、冻寒之触、魔能爆、燃火术、毒气喷溅、圣火术、恶言相加。
- 一环：妖火、狂笑术、睡眠术、七彩喷射、油腻术、纠缠术、虚假生命、法师护甲、大步奔行、跳跃术、英雄气概、曳光弹、炼狱叱喝、猎人印记、神恩、疗伤术、治愈真言、灾祸术、祝福术、虔诚护盾、致伤术、魔法飞弹、护盾术、燃烧之手、雷鸣波。
- 二环：隐形术、朦胧术、树肤术、防护毒素、变巨／缩小术、火焰刀、灵体武器、目盲／耳聋术、人类定身术、次级复原术、灼热射线、粉碎音波、强酸箭、月华之光、荆棘丛生、炽焰法球、黑暗术。
- 三环：群体治愈真言、防护能量伤害、法术反制、解除魔法、火球术、闪电束、灵体卫士、昼明术、召雷术、飞行术。
- 四环：高等隐形术、防死结界、放逐术、枯萎术。
- 五环：怪物定身术、群体疗伤术、寒冰锥、焰击术。
- 六环：医疗术、死亡法阵、连锁闪电、解离术、冰封法球（立即发射模式）。
- 七环：死亡一指。
- 八环：律令震慑、阳炎爆。
- 九环：群体医疗术、律令死亡。

其中死亡一指造成的伤害已结算，但人形生物死亡后的僵尸生成仍由 DM 裁定。燃烧之手、雷鸣波、粉碎音波、火球术、闪电束、死亡法阵、寒冰锥、冰封法球与阳炎爆已有锥形／立方体／球形／直线地图模板；选中法术时显示尺寸和高亮格，点击地图会自动框选范围内 Token。DM Authority 仍会复核射程、最大目标数和连锁目标关系。

焰击术使用 10 尺半径范围模板，火焰与光耀伤害分别结算目标的抗性、免疫和易伤，再合并为同一次伤害应用；升环时由施法者选择把额外伤害骰加入火焰或光耀。强酸箭在未命中时只结算初始伤害的一半；命中时把后续强酸伤害保存为带来源的 `ActiveEffectInstance`，并在目标下一回合结束时由 Headless 自动触发。后续伤害在触发时重新读取目标的强酸抗性、免疫和易伤，且通过正常伤害链处理专注与生命值。

所有短期与持续状态统一使用可持久化 `ActiveEffectInstance`：效果会随角色或未关联怪物 Token 同步，且只能由 Headless 在施法者／目标回合边界或声明的中断触发点推进。冷冻射线实际限制移动与疾走；电爪会检查金属护甲优势并封锁反应；阳炎爆对亡灵／泥怪施加豁免劣势并结算重复豁免。妖火会压制隐形收益，普通隐形术在攻击或施法时只解除对应目标，最后一个目标解除时同步结束专注；树肤术、防护毒素与防死结界分别接入 AC 下限、毒素抗性和死亡拦截。大步奔行的 10 尺速度加值会进入角色、地图行动经济和 Headless 有效速度；跳跃术会把长跳与高跳的权威距离上限变为三倍，但不会减少实际移动消耗；飞行术会授予 60 尺飞行速度，按海拔与三维路径消耗移动，并在空中 Token 右上角显示飞行标记；英雄气概会移除并免疫恐慌，在目标回合开始按施法者施法属性调整值刷新临时生命，并在对应专注效果结束时只撤销该法术仍然提供的临时生命。防护能量伤害由施法者选择五种合法伤害类型之一，专注状态只对所选类型提供抗性。自动怪物和手动怪物推进走同一权威事务。

变巨／缩小术在施法时要求选择形态；友方目标视为自愿，敌对目标必须进行体质豁免，成功则不生成效果。生效后，体型等级、力量检定和力量豁免的优劣势，以及玩家武器、借机攻击、野性变身与 SRD 怪物武器攻击的 `±1d4` 均由同一 ActiveEffect 投影进入权威结算；缩小的武器伤害最低保留 1 点。当前地图 Token 占格不会在法术中途扩张，物件目标与空间不足时的最大可容纳尺寸仍由 DM 裁定。

火焰刀首次施放会消费附赠动作和法术位，并在施法者身上建立最长100轮的专注 `ActiveEffectInstance`；效果会保存原始施法环位。此后法术栏提供独立的“火焰刀攻击”按钮：选择5尺内敌对目标后消费动作，进行近战法术攻击，命中造成3d6火焰伤害，并在4／6／8环分别增加至4d6／5d6／6d6。该攻击复用普通法术攻击的优势／劣势、暴击、护盾术、抗性、专注检定和战斗日志，但不会重复消费法术位、触发反制法术或被记作再次施法。当前分层光源模型尚不能安全叠加火焰刀的10尺明亮光照和额外10尺微光；丢下刀刃与用附赠动作重新唤出的持握状态也仍由 DM 裁定。

灵体武器首次施放会在 60 尺内建立独立、非专注的地图效果实体，并立即用附赠动作对其 5 尺内的敌对目标进行近战法术攻击；命中造成 `1d8＋施法属性调整值` 力场伤害。此后法术栏会按每一个仍有效的灵体武器实例提供“移动并攻击”入口：同一个附赠动作内先沿合法路径移动至多 20 尺，再对新位置 5 尺内的目标攻击。4／6／8 环施放时分别提升至 2d8／3d8／4d8；Host 会同时复核施法者、原始环位、地图实体、ActiveEffect 实例 ID、移动距离、墙体阻挡、目标距离、掩护、行动经济和骰值，后续攻击不会重复消耗法术位或触发反制法术。

召雷术首次施放会以施法者当时所在格为水平中心建立固定的60尺半径雷云，并在云下选择5尺半径落雷点。范围内所有生物分别进行敏捷豁免，失败受到3d10闪电伤害，成功减半；每升一环增加1d10。专注期间，法术栏按该雷云实例提供“再次召雷”入口：消耗动作，在云中心60尺内重新选择落雷点，不再次消耗法术位，也不再次触发反制法术。Host 会复核施法者、专注、原始环位、雷云实例、落点范围、完整受影响目标、豁免与骰值；落雷不会移动雷云。当前地图没有权威的天花板容积和天气强度字段，因此“室内无法容纳雷云时施法失败”及“室外暴风天气额外1d10”明确保留为DM裁定，不会静默套用。

狂笑术会在施法前拒绝智力 4 或更低的目标；失败后以同一专注来源施加倒地、失能和无法站起。目标仍可爬行，但不能主动起身。其回合结束时会重复感知豁免；每次受到伤害还会建立 Host 持有的待处理豁免并按优势结算。任一重复豁免成功都会原子移除整组效果、清理跨端待处理状态并结束施法者对该目标的专注。

睡眠术由 Host 重算20尺半径内的全部生物并掷5d8生命值池，升环每环增加2d8。结算按当前生命值从低到高进行，忽略已昏迷、亡灵和魅惑免疫生物；受影响目标陷入昏迷并倒地。昏迷会在1分钟结束、受到伤害或相邻生物消耗一个动作唤醒时结束，倒地状态不会随醒来自动移除。
油腻术会创建持续10轮、无需专注的10尺方形权威区域。区域提供困难地形，并在首次创建、任一生物进入区域以及生物在其中结束回合时发起敏捷豁免；失败通过 `ActiveEffectInstance` 施加倒地，直到目标主动起身。区域触发支持标准豁免修正、状态免疫、DM Interrupt、收据去重与多端同步。
纠缠术会创建持续10轮、需要专注的20尺方形权威区域。区域提供困难地形，但只在区域首次创建时要求其中生物进行力量豁免；失败通过 `ActiveEffectInstance` 施加束缚，并将状态生命周期绑定到施法者的纠缠术专注。被束缚者可消耗一个动作进行力量检定，对抗施法者在施法时快照的法术豁免 DC；成功时仅解除自身束缚，不会错误结束整片区域或施法者专注。

黑暗术、昼明术、月华之光与炽焰法球现在使用同一份声明式地图光照数据。权威可见性与画布遮罩共同读取明亮／微光半径、魔法黑暗、环级压制、墙门遮挡和区域锚点；炽焰法球移动时光源随效果 Token 移动。黑暗术与昼明术当前支持固定落点模式；依附物件、遮盖光源、舞光术的四个独立光团和不灭明焰的永久物件绑定仍保留为 DM 裁定，未被错误标记为完整 Headless。

朦胧术已作为施法者自身的专注效果接入所有权威攻击入口：普通武器、怪物动作、借机攻击、武僧与猎人多重攻击、核心法术攻击及插件法术攻击都会获得劣势。攻击者只有在目标处于其盲视或真实视觉范围内时才能忽略该劣势；震颤感知不被误当作看穿幻象的视觉。

法师护甲只允许以未穿护甲的自愿生物为目标，并直接进入攻击命中的 AC 权威计算（13＋敏捷调整值），不是仅显示状态标签。解除魔法会枚举目标身上的 SRD 法术来源：不高于施法环级的效果自动结束；更高环级效果逐项掷施法属性检定，Headless 复核 DC、骰值与效果 ID，失败的效果保持不变。当前自动入口以生物 Token 上的法术效果为范围；物件和独立地图魔法效果仍由 DM 裁定。

## 下一批：核心持续区域法术

月华之光、灵体卫士、荆棘丛生、炽焰法球与召雷术已经接入核心持续区域事务。月华之光会令变形生物以劣势进行豁免，并在失败时发出恢复原形的权威事件；具体替换形态资料仍要求该生物的变形系统提供原形快照。炽焰法球拥有独立效果 Token，可由施法者花费附赠动作移动30尺；其移动会被墙阻挡、撞上路径中的第一个生物即停止，撞击与附近生物回合结束均走敏捷豁免、升环火焰伤害和 DM Interrupt。召雷术使用固定雷云边界和每回合重新选择的5尺落雷模板，两者不会被错误合并为可移动区域。

## 暂不应直接标记 Headless 的类型

- 持续区域底座已经支持权威地图实体、首次创建／进入／回合开始／回合结束触发、每轮去重、豁免、伤害、状态、移动路径检测、专注清理和 DM 中断；各法术仍需逐项声明其具体触发模板。
- 召唤与独立实体底座已支持单体 SRD 5.1 生物：带所有者、DM 操作、独立先攻、阵营、持续时间、专注解除、0 HP 离场和多端同步。灵体武器已作为非生物效果实体走独立权威链路；多只生物共享先攻、玩家移交控制和各具体召唤法术的选择限制仍需逐项接入。
- 复杂控制：命令术等仍需要标准化自动回合行为；睡眠术、狂笑术、人类定身术和目盲／耳聋术已经接入标准状态与生命周期链路。
- 施法打断：法术反制、解除魔法等，需要在被反制法术消费资源和提交结果前暂停原事务，并支持反制嵌套。
- 地形、传送与立体移动：迷踪步、任意门、墙类法术等，需要合法落点、视线、碰撞、区域和高度模型。
- 纯探索／叙事法术：侦测魔法、鉴定术、预言类和多数幻术。它们可以保留结构化规则与 DM 裁定，不必为了提高 Headless 数量而伪造自动结算。

## DM 裁定与自动战斗中断边界

未机械化但已被角色学习／准备的动作与附赠动作法术现已进入地图法术栏，并通过 `dnd5e-adjudicated-spell`＋`dm-adjudication` 事务处理。玩家请求不会立即扣资源；DM 可填写最终伤害、治疗、临时 HP、状态增删、专注轮数与备注，批准后才由 Headless 原子消费动作和法术位并应用结果。取消、十分钟超时、回合变化或最终复检失败均不消费。反应法术仍不开放普通按钮，必须等待对应触发器接入。

自动结算事务仍不允许 DM 在 resolver 已完成后静默修改结果。首版 DM 专用 `dm-adjudication` Interrupt 已按以下边界实现：

1. DM Authority 完成 preflight 和骰值准备，但不提交 Headless 结果。
2. 生成包含事务 ID、行动、目标、骰值、DC 和拟应用结果的 DM-only interrupt。
3. DM 选择“批准并提交／取消施法”，修改项只能使用白名单字段。
4. Authority 应用经过 Headless 校验的裁定 action；不得直接写内部 Store。
5. 一次性提交角色、Token、行动经济、资源、ACK 和战斗日志。DM 修改必须在所有客户端的日志中可见。
6. Interrupt 具备超时默认分支、幂等 ID 和单次消费；插件只能请求该 capability，不能自行批准或写共享状态。

首版已开放：最终伤害、治疗、临时 HP、目标排除（不添加该目标效果）、附加／移除条件、专注持续轮数、裁定备注和通用持续区域。检定 DC 临时修正与更多反应法术仍需逐项接入；任意脚本、任意 Store patch、跳过 DM 身份验证或结算后无日志改血都不开放。
