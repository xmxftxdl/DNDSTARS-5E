# 地图图片墙体识别基准（2026-07-24）

## 结论

图片识别已经从实验性暗线扫描升级为可交互使用的墙线候选工具，但仍不应替代 DM 确认：

- 10 张带 UVTT 真值的公开地图按线长加权后，Precision 为 `10.48%`、Recall 为 `14.32%`、F1 为 `12.11%`。
- 相同语料的旧暗线扫描实现为 `0.95% / 10.10% / 1.74%`，新实现的 F1 提高约 `6.96 倍`。
- 14 张地图的缓存后单图中位耗时为 `181.1 ms`。110 MB、12,880×6,720 的彩绘飞艇图首次解码与分析为 `1.35 s`，同一文件调参重算约 `165 ms`。
- 候选数量被控制在每图 `70–456` 条；旧实现曾在同类图上产生数千到上万条候选。
- 黑线白底、白线黑底、横直墙、斜墙和曲墙均无需手动选择极性。
- UVTT/DD2VTT 自带 `line_of_sight` 时，产品始终直接导入矢量墙体。本文对 UVTT 图片再次识别只用于与其矢量数据做离线准确率对照，不是生产导入流程。

## 实现

生产识别器执行以下流水线：

1. 最长边缩放到 1,600 px，并按 `File + 分析尺寸` 缓存解码后的 RGBA；调参重算不再重复解码 100 MB 级图片。
2. 在 Web Worker 中转移一次性像素缓冲，避免主线程复制；转灰度、盒式模糊并计算 Sobel 梯度。
3. 从每张图的梯度分布计算自适应阈值，边缘滑块作为相对倍率生效，因此同时支持深色线、浅色线和不同对比度。
4. 用方向量化与投影桶提取任意角度长线；用局部 PCA 将曲墙近似成可编辑折线段。
5. 合并近似共线段，识别并移除覆盖全图的规则网格，按置信度与长度排序，并限制为最多 1,200 条候选。
6. 可选“仅主体”模式对横图忽略上下背景带、对竖图忽略左右背景带；也支持显式 ROI。候选只显示为青色预览，DM 可逐条删除后再接受。

## 语料与方法

原始样本只放在系统临时目录，测试完成后删除，没有提交到仓库。

| 类别 | 数量 | 来源 |
| --- | ---: | --- |
| DungeonDraft 实际地图 | 5 | [`mbround18/vtt-maps`](https://github.com/mbround18/vtt-maps)：demo、simple-room、road-side-in、pools-of-mystery、slums-office |
| UVTT 转换器测试资源 | 5 | [`SangzorDeGeit/vtt_rust`](https://github.com/SangzorDeGeit/vtt_rust)：example1–example5 |

| 复杂彩绘大图 | 1 | 用户提供的 CZEPEKU 飞艇图，仅在本次临时测试中使用 |

- 默认参数：边缘倍率 `22`、最短线比例 `0.025`、分析最长边 `1600 px`、全图模式。
- 每张地图连续运行 3 次；表中耗时为中位数，因此反映同一图片调参时的缓存后延迟。
- UVTT 真值取 `line_of_sight + objects_line_of_sight`，按 `map_origin`、`map_size` 和 `pixels_per_grid` 映射到实际图片。
- 沿预测线和真值线等距采样；采样点落在另一组线段容差范围内即视为命中。评分按线长加权，不会因一条墙被拆成多个曲线近似段而额外扣分。
- 扫描图没有矢量真值，只记录候选数量、耗时并人工检查叠加层。

## 参数校准

边缘值现为相对每张图自适应阈值的倍率。公开真值集扫描结果：

| 边缘值 | Precision | Recall | F1 |
| ---: | ---: | ---: | ---: |
| 22（默认） | 10.48% | 14.32% | 12.11% |
| 28 | 8.33% | 9.49% | 8.87% |
| 34 | 6.41% | 5.42% | 5.87% |

默认值 22 保留。更高值适合候选过多的纹理图，但会降低召回；“最短线”和“仅主体”可与它组合使用。

## 产品边界

- UVTT/DD2VTT：直接导入矢量墙、门、光源和内嵌图片，不运行图片识别。
- PNG/JPEG/WebP：生成非权威候选；DM 调参、删除误报并明确接受后才写入 Schema V3 墙体。
- 复杂彩绘图中的家具、阴影、水浪和墙体具有相似边缘，仅靠通用几何无法稳定做语义区分。若未来要自动区分，应另行引入可版本化的语义分割模型和标注数据，不能把当前候选器静默升级成自动权威写入。
