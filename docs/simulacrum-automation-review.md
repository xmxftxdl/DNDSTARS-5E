# 拟像术：自动化与操作说明

本项目沿用 2014 / SRD 5.1 规则。本次重点重写角色拟像的数据隔离和施法预检查。

## Foundry VTT 可借鉴之处

Foundry 的 Actor 可以复制，并单独给玩家 Owner 权限。未链接 Token 有独立资源；链接同一个 Actor 的 Token 会共享资源。因此拟像不能简单复用本体的资源池。

- [Actor 与权限](https://foundryvtt.com/article/actors/)
- [Token 的 Link Actor Data 与独立资源](https://foundryvtt.com/article/tokens/)
- [Actor Delta 与副本数据](https://foundryvtt.com/article/v11-actor-delta/)

Chris's Premades 提供基于 Midi-QOL 的自动化，但本次未能取得其拟像术专用脚本，不能声称已核实它对法术位、材料或修复的全部处理。[模块说明](https://foundryvtt.com/packages/chris-premades)

本项目采用地图 Token 保存拟像状态、创造时保存角色能力快照的方式，不引入 Foundry 插件依赖。

## 规则与数据

| 项目 | 行为 |
| --- | --- |
| 施法 | 7 环，12 小时，触及野兽或类人生物；材料为价值 1,500 gp 的红宝石粉末等。材料检查仍遵循当前房间设置。 |
| 生命值 | 上限为被复制生物上限的一半，向下取整；生命值和临时生命值独立于本体。 |
| 法术位 | 复制创造时剩余资源，使用后只扣拟像；复制自己时不返还此次施法已经花掉的环位。不能通过本体休息恢复。 |
| 职业与法术 | 新生成的角色拟像保存职业选择、法术、专长与授权快照；本体后来换法术或升级不会同步提高拟像。 |
| 专注与状态 | 使用拟像自己的地图状态，不继承本体当前专注或临时状态。 |
| 装备 | 初始没有装备，不复制本体背包和货币。需要材料或法器的施法仍受房间前提设置约束。 |
| 修复 | 现有 DM 数据卡提供炼金修复入口，每点生命值对应 100 gp 材料；普通治疗和休息不能代替修复。 |
| 先攻 | 沿用施法者先攻，显示拟像自己的行动栏位；双方动作与资源分开。 |
| 销毁 | 生命值降至 0 时离场；现有同地图再次施法会替换旧拟像。 |

## 玩家如何操作角色拟像

1. 拟像生成后会在地图上出现独立棋子。
2. 战斗先攻轮到拟像时，底部行动栏显示拟像的生命值、法术与资源。
3. 施法者的玩家负责移动、选择行动和投掷；复制其他玩家的角色不把控制权交给那个玩家。
4. 消耗写入拟像棋子，刷新后保留；本体的法术位、生命值和专注保持独立。

## 验证及边界

自动测试覆盖拟像施法、本体无环位而拟像有环位、本体恢复环位而拟像仍耗尽、专注隔离、复制其他角色的控制归属，以及现有拟像创建、先攻和普通治疗限制。未在真实房间进行完整浏览器施法测试。

旧拟像没有创造时的完整职业快照，无法追溯恢复；新快照适用于重新创造的拟像。此次没有改动现存拟像或真实角色资源。

跨地图唯一性、复制无角色卡的野兽后完整玩家行动栏，以及独立拟像装备管理，仍需要后续专门实现；不能把本次角色拟像修复视为这些流程已经完成。
