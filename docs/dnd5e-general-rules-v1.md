# D&D 5e 2014 通用规则 V1

本阶段把六项高频通用规则接入现有 DM authority、房间同步和 Headless 结算，不引入旧 AP 或攻防差值规则。

## 突袭

- DM 点击“开始战斗”后先选择未察觉威胁的参战单位。
- 受突袭单位在自己的首回合结束前不能移动、采取动作或进行反应；结束该回合后状态由权威端解除。
- 7级野蛮人的野性直觉允许其先进入狂暴，再正常行动。该例外读取野蛮人职业等级，不读取角色总等级。
- 突袭状态同时写入角色或未关联角色的 Token，刷新、重连和多端同步不会丢失。

## 移动、跳跃与坠落

- 地图移动事务支持步行、攀爬、游泳、助跑跳远和立定跳远，并由 Headless 重新计算移动力消耗。
- 没有对应速度时，攀爬或游泳每移动1尺额外花费1尺移动；有对应速度时按速度比例结算。
- 助跑跳远上限等于力量值，立定跳远减半；高跳使用 `3 + 力量调整值`，立定高跳减半。
- 选择“坠落”且海拔下降10尺或更多时，权威端要求每10尺一枚 d6，最多20d6；伤害进入统一伤害、临时生命、专注、0 HP 和死亡链，并在仍存活时施加倒地。攀爬或沿地形受控下降不会被误判为坠落。
- 当前 V1 由玩家或 DM 明确选择移动模式和目标海拔。助跑前实际10尺路径、武僧轻身坠反应、疾风步跳跃翻倍、飞行悬停和液面／墙面移动仍应作为下一层地图路径能力处理。

## 魔法物品同调

- 库存实例保存 `attunementPending`、`attuned` 和 `attunedAt`；转交物品不会转移同调。
- 玩家先选择一件物品准备同调，完成一次短休后才生效；同一次短休至多完成一件。
- 每名角色最多同时同调三件物品。种族、阵营、施法者和职业前置条件由 Host 校验；无法结构化判断的前置条件要求显式确认。
- 需要同调的装备只有在对应库存实例已同调时，其 AC、攻击、豁免、速度和 Headless 效果才会生效。结束同调会立即关闭这些效果。
- 当前 V1 尚未自动处理“离开物品100尺超过24小时”、另一生物完成同调或角色死亡造成的同调断开；这些低频解除条件暂由 DM 点击“结束同调”。

## 兼职

- `dnd5eClassLevels` 保存12个核心职业的独立等级；旧存档自动迁移为单职业，`level` 始终是总等级，`charClass` 保留起始职业。
- 升级界面检查当前职业与目标职业的2014属性门槛，总等级上限20。起始职业不能在已有兼职后被下拉框意外替换。
- 熟练加值按总等级；职业特性、子职、资源、额外攻击、伤害骰和职业等级门槛按对应职业等级。
- 固定生命值按起始职业的完整1级生命骰及以后各职业等级分别计算，生命骰按骰面分池。
- 全施法职业等级与半施法职业等级向下取半后合并法术位；邪术师契约魔法保持独立。法术书和战斗职业面板可切换各施法／职业来源。
- 进入兼职获得的武器与技能熟练按2014兼职表收窄；不会重复授予起始豁免或起始装备。
- 当前 V1 尚未结构化乐器、盗贼工具和完整护甲不熟练惩罚，这些字段在对应工具／护甲事务落地前由 DM 记录。

## 特殊感官

- SRD 怪物的盲视、震颤感知和真实视觉从 stat block 转换为带范围的结构化数据；DM 也可给玩家 Token 设置范围。
- 盲视和真实视觉可在范围内绕过黑暗与隐形，但仍受阻挡视线的墙、关闭门和高度遮挡限制。
- 震颤感知只提供位置探测，不等同于“看见”；目标飞行或与观察者不在近似同一表面时无效。
- 服务端安全投影只向玩家发送真正可见的完整隐藏 Token；仅被震颤感知定位时发送删减后的占位信息。
- 幻象真伪、以太位面、变形者原形和精确的“同一连续表面”拓扑尚无通用模型，因此真实视觉与震颤感知的这些分支仍由 DM 裁定。

## 验证边界

相关规则都有纯函数单测；突袭、坠落、特殊感官和兼职资源另有 Headless／资源层回归。构建必须通过 TypeScript 项目引用检查，最终仍需在5273／5274进行房间级开始战斗、移动、短休、刷新和重连 E2E。
