# 场景编排系统 V2

场景编排把地图、讲义、日志、环境说明、氛围音效与声明式触发动作组合成可运行场景。入口位于地图页右上角的“场景编排”。

## DM 工作流

1. 在地图上建立场景，填写说明、环境标签，并选择已存在的讲义和战役日志作为场景资料。
2. 新建触发区域，选择圆形或矩形后直接在地图画布上拖拽。
3. 设置进入/离开事件、Token 类型和重复策略。
4. 按顺序添加动作。预览会显示执行计划，不会修改房间状态。
5. 选择一个 Token 手动试跑；正式运行时，Token 进入或离开区域会由 DM 端排队执行。

运行队列可以暂停。暂停后“单步”每次只提交一个动作；继续则恢复自动执行。失败动作会暂停队列并保留当前位置，DM 修正绑定后可以重试，也可以丢弃本次运行。

## 地图互动点

互动点用于书柜、宝箱、祭坛、机关等可点击场景物件。它与自动触发区域不同：玩家必须控制自己的角色靠近并主动点击，DM 不能代替玩家发起互动。

1. DM 在战斗开始前打开场景编排，为当前地图新增互动点。
2. 选择“放置到地图”，再点击互动物件所在位置。战斗开始后会锁定互动点编辑，避免结算途中改变距离、DC 或奖励。
3. 设置图标、交互距离、属性或技能检定、DC、优势/劣势、成功与失败文本。
4. 设置重复规则：全房间一次、每个角色一次或不限次数。
5. 从 SRD 5.1 或当前房间规则包的物品模板中配置一项或多项奖励。
6. 分别配置成功与失败的有序结果：金币、讲义、任务、陷阱伤害或标准状态。结果可上移、下移，因此一个机关可以依次造成伤害、施加中毒，再发布线索与任务。
7. 玩家角色进入交互距离后点击标记，DM 会收到裁定窗口。DM 可以让系统掷骰，也可以直接判定成功或失败。
8. Host 按最终结果执行对应序列，并记录角色收据和房间副作用收据；刷新、断线重连或重复点击不会再次发放。

玩家端只会收到 DM 明确设为可见的互动点名称、图标、位置、距离和提示。检定 DC、奖励、成功/失败文本、结果序列与隐藏互动点不会投影到玩家端；玩家请求也只包含互动点 ID，Host 会重新读取私有配置并校验角色归属、距离、检定、物品模板、讲义和任务引用。

### 互动结果语义

- 金币与物品使用同一个角色库存原子提交和收据。任何模板、数量或金额无效时，整组发放失败。
- 陷阱伤害进入 Headless 伤害管线，正常处理抗性、免疫、易伤、临时生命、专注与降至 0 HP。
- 标准状态只通过 `ActiveEffectInstance` 工厂写入，遵守状态免疫、覆盖规则和持续轮数。
- 讲义可以先在“通讯与日志”保存为仅 DM 可见的草稿。互动成功后可发布给触发玩家或全体玩家。
- 任务可以新增，也可以将一个已有共享任务标记为完成。
- 房间讲义/任务使用独立的有界幂等收据。若网络写入中断，重试会补齐尚未提交的部分，而不会重复已完成的副作用。
- 互动结果会写入战斗日志，包括检定总值、DC、实际伤害、状态和已触发的讲义/任务。

## V1 动作

- 展示已绑定讲义，面向全体或触发角色所属玩家。
- 向触发角色所属玩家发送密语。
- 发起群体属性检定、技能检定或豁免。
- 开门、关门或上锁。
- 设置明亮、昏暗或黑暗环境光。
- 完全遮蔽或清除当前地图迷雾。
- 按 SRD 怪物目录投放遭遇，并可立即开始先攻。
- 播放内置发现、危险、机关、神秘或胜利音效。
- 播放或停止 DM 导入的房间同步音乐、环境音和音效。
- 将触发 Token 传送到另一地图/楼层。
- 写入共享任务或战役日志。

## 撤销语义

V1 支持撤销门状态、环境光、未开始先攻的遭遇投放和 Token 传送。讲义、密语、检定、日志、任务、迷雾全量操作以及已经开始的战斗属于已产生外部结果的动作，不做伪撤销；面板会把它们标记为不可撤销。

## 权威与隐私

完整场景资源只允许 DM 写入。玩家和观战者读取时，服务端会把触发区域、遭遇预设、待执行队列、回执和历史全部投影为空；他们只能收到 DM 已发布的讲义、密语、检定或音效结果。服务端还会在落盘前校验区域、动作白名单、数量上限和运行队列，损坏数据会 fail closed。

## 房间同步音频

DM 可在场景面板的“房间场景音频库”导入 MP3、Ogg、WAV、M4A、AAC 或 WebM 文件，单文件上限为 24 MiB。文件、目录和播放状态都按房间隔离；玩家不能上传、删除、播放或伪造播放状态。

场景可以绑定一个导入音频作为背景音乐或环境音，也可在动作序列中播放或停止音频。播放、暂停、继续、停止、循环和房间音量由服务端统一盖时间戳。客户端通过服务器时钟校正播放位置，因此刷新、重新加入和设备时钟偏差不会让音轨从头播放。浏览器若因自动播放策略阻止声音，会显示“启用场景音频”，玩家点击一次后立即追上房间进度。

内置短音效仍使用本地 Web Audio 合成，不访问网络。导入音频也不会加载任意远程 URL。
