# 法术投骰归属约定

- 命中骰、伤害骰属于施法者；反应法术属于实际施放反应法术的角色。
- 豁免骰属于执行该次豁免的角色，其加值骰及重投沿用同一归属。
- 持续区域和延迟伤害沿用来源施法者，不随当前回合或受伤目标改变。
- 其他角色检定属于执行检定的角色。只有自由投掷允许没有角色归属。
- 玩家拥有的投掷交给对应玩家端执行；连接失败或超时停止流程，不转交 DM 代投。DM 的结果验证不改变骰子归属。

## 检查方式

运行 `node scripts/audit-dice-ownership.mjs` 更新 [逐法术扫描报告](dice-ownership-audit.json)。报告覆盖当前目录中的 319 个 SRD 法术条目、地图公共投骰入口的直接调用，以及 Activity 声明的施法者和目标归属。

报告中的条目覆盖数不等于全部法术已自动化，也不代表逐个法术进行了浏览器实测。核心法术通过公共入口及调用点检查；Activity 声明通过计划器检查。浏览器回归另行覆盖火焰箭、强酸箭及延迟伤害、DM 验证和自由投掷队列。

运行 `npx vitest run src/pages/maps/diceOwnership.test.ts` 检查无归属投骰的运行时拦截与调用点遗漏。多目标、持续区域、豁免中断、反应结算和玩家回传的回归测试位于相应模块测试文件中。
