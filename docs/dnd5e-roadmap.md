# D&D 5e 规则迁移路线

## 阶段 1：Ruleset Adapter

定义回合生命周期、动作验证、攻击、豁免、伤害和休息接口；现有 UI 与消息层只提交 action、展示 result。

当前状态：已建立 `dnd5e-srd-5.2.1` 纯规则适配器、注册入口和单元测试。它不依赖 UI、Store 或旧 Headless 引擎；后续权威层迁移必须通过此接口结算，旧 AP 与攻防差值规则不得进入适配器。

## 阶段 2：角色数据

建立 D&D 5e 角色模型和旧示例数据清理，加入动作/附赠动作/反应、移动力、生命骰、法术位和专注。

## 阶段 3：基础战斗

实现先攻、攻击检定、优势/劣势、AC、伤害、豁免、借机攻击、倒地与死亡豁免。

## 阶段 4：SRD 内容

以结构化数据接入职业、装备、法术、状态和怪物，并记录 SRD 版本及 CC-BY-4.0 署名。

## 阶段 5：多端与模拟

复用 DM authority、Interrupt Queue 与 Headless 引擎，补齐三玩家、多怪物、断线重连和批量平衡模拟。
