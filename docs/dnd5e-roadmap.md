# D&D 5e 规则迁移路线

## 阶段 1：Ruleset Adapter

定义回合生命周期、动作验证、攻击、豁免、伤害和休息接口；现有 UI 与消息层只提交 action、展示 result。

当前状态：已建立 `dnd5e-2014-srd-5.1` 纯规则适配器、注册入口和单元测试。它不依赖 UI、Store 或旧 Headless 引擎；后续权威层迁移必须通过此接口结算，旧 AP 与攻防差值规则不得进入适配器。

## 阶段 2：角色数据

建立 D&D 5e 角色模型和旧示例数据清理，加入动作/附赠动作/反应、移动力、生命骰、法术位和专注。

角色 Setup 已把新手推荐扩展为十题画像：战斗方式、队伍定位、力量来源、操作复杂度、魔法投入、生存方式和非战斗专长实际参与 12 职业加权排序，种族气质与两条阵营轴分别参与种族和九宫格阵营建议。问卷会实时展示前三职业及匹配度；确认页再按所选职业主属性、实际基础加点和 2014 固定种族调整重排前三种族，并明确提示当前种族是否是数值首选。推荐理由与结构化推荐记录会随角色保存到角色笔记和 `dnd5eCreationRecommendation`，仅用于解释构筑，不参与 Headless 规则结算。

## 阶段 3：基础战斗

实现先攻、攻击检定、优势/劣势、AC、伤害、豁免、借机攻击、倒地与死亡豁免。

## 阶段 4：SRD 内容

以结构化数据接入职业、装备、法术、状态和怪物，并记录 SRD 版本及 CC-BY-4.0 署名。

当前状态：已建立独立的 SRD 5.1 怪物模型、首批 10 个常用怪物、地图选择器与 Token 转换，并把按怪物速度移动、每回合一个动作、普通武器攻击、伤害易伤／抗性／免疫和枭熊多重攻击接入纯 5e Headless；SRD 怪物回合不读取或消费旧敌人 AP。尚待继续导入完整 SRD 怪物目录，并实现击倒豁免、亡灵坚韧、充能、范围能力、施法和传奇动作等结构化效果。

物品栏状态：已建立“模板＋实例＋数量＋装备槽位”的 SRD 5.1 库存模型，角色页按装备／道具显示 RPG 图标格并在悬停时展示完整规则信息；DM 可从房间玩家名册分发模板物品，玩家的使用、丢弃、转交、装备与卸下均通过 DM 权威事务同步。Rules Plugin API V2 已开放 `registerItem`，可从 Worker 安全导入自定义武器、装备和消耗品；Host 会校验声明并把固定命中、伤害、AC、豁免与速度修正投影进 Headless。治疗药水已进入战斗行动队列，权威端检查动作、掷 `2d4+2`、更新角色／Token 生命值并消费库存。滚珠、铁蒺藜与捕猎陷阱已接入地图选点、持久区域、DM 权威校验、玩家与 SRD 怪物移动路径触发、敏捷豁免、伤害／状态和半速谨慎移动；捕猎陷阱逃脱事务与投掷瓶攻击仍是下一阶段。详见 `docs/inventory-system.md`。

职业状态：12 个 SRD 5.1 职业及各自唯一的 SRD 子职已建立结构化 1–20 级目录，并接入角色职业页、技能／子职／战斗风格／专精／宿敌／地形／超魔法／魔能祈唤等选择、法术位与职业资源、短休／长休恢复、基础装备、无甲防御、职业速度、额外攻击和龙族韧性生命值。地图上的 5e 非战士不再进入旧 AP 技能栏，而与战士共用 5e Headless 武器攻击与回合行动经济。复杂职业效果与完整 SRD 法术目录仍需逐项接入 Headless；在实现前只显示规则文字，不得伪装成已自动结算。

职业 Headless 动作进度：除狂暴、圣疗、身心合一、维持生命与术法点转换外，已加入鲁莽攻击、狂战士狂乱／威吓气势／报复、游荡者偷袭／巧妙动作／幸运一击的攻击侧、猎人巨像杀手／灭群者／巨人杀手反应、20级游侠屠灭众敌、圣武士至圣斩／神圣武器／神圣感知／净化之触、武僧武艺／疾风连击／疾风步／耐心防御／震慑拳／心如止水／空灵体，以及德鲁伊荒野变形、形态生命池和野兽攻击。净化之触要求明确选择接触目标身上的一个持续法术，多目标专注不会错误地从所有目标移除。法师奥术回想、法术精通与招牌法术已经具备选择、免位施法、独立短休资源和DM端复核；塑能学派“法术塑形”允许区域塑能法术把盟友与敌人一并列为受影响生物，再选择至多1＋法术环级个非施法者目标自动通过豁免且免受成功减半伤害，保护名单及数量由DM Headless复核；14级“超限导能”可选择令1至5环法师塑能伤害法术取最大骰，Headless 会追踪长休前次数并结算后续使用的不可减免 d12 反噬。术士已有谨慎、远距、强化、升阶、瞬发、无声和孪生七种可用超魔法；孪生法术要求两个不同合法目标，并按当前施法环级消耗术法点（戏法为1点），每个目标独立结算攻击骰、豁免与伤害；强化法术在伤害骰公开后通过多端共享中断让施法者选择至多魅力调整值枚骰，由DM重掷并强制采用新结果，可与另一种超魔法并用，跨孪生法术伤害组共用骰数上限。延时规则已进入引擎但尚缺机械化的术士持续法术。龙族血脉“元素亲和”现在同时覆盖一次伤害加值与施法时消耗1术法点获得同源抗性1小时；Headless 会合并计算超魔法与抗性费用，状态跨刷新及多端持久化。吟游激励不再只是挂状态：持有者可在攻击或豁免失败时通过多端 Interrupt 选择掷出并消耗激励骰，Headless 验证骰面、10分钟期限与状态清除。不屈和金刚魂也已覆盖法术豁免、震慑拳与专注豁免。邪魔宗主“黑暗之主的幸运”已通过独立共享中断覆盖所有现有战斗豁免并由 Headless 消耗短休资源；地图还缺少通用属性检定事务，故属性检定侧未完成。“坠入地狱”已覆盖武器、借机和法术攻击，未命中不消费，目标跨角色／Token 快照放逐至邪术师下一回合结束后返回并结算10d10，邪魔免除伤害。秘法奥秘已提供完整21个6–9环邪术师法术选项、四份独立长休资源及DM端环级／资源复核，死亡法阵、死亡一指与律令死亡可在地图结算，5环契约位不能冒充秘法奥秘。目标距离、职业／子职／等级、动作经济、资源、命中与豁免均由 DM 端重新验证；状态通过角色或未关联角色的生物 Token 持久化。秘法奥秘其余复杂法术、精确范围模板及其余子职复杂效果仍须继续机械化。

战士勇士审计：SRD 5.1 核心包唯一的战士子职是勇士；其精通重击、运动健将、额外战斗风格、卓越重击和生存者五项特性均已进入数据与实际结算。生存者由 DM 权威 Headless 在回合开始同时更新角色和 Token。战士不屈会在失败豁免后由目标玩家选择是否重掷，资源消费和“必须采用新结果”由 Headless 执行。双武器战斗已按“先完成轻型近战武器攻击动作，再用附赠动作以另一把轻型近战武器攻击”接入，只有对应战斗风格才把属性调整值加入副手伤害；防护战斗风格已通过共享中断覆盖武器、怪物多重、法术和荒野变形攻击，并由 Headless 校验盾牌、盟友和反应。旧存档空规则集标识会被强制迁移为 SRD 5.1，兼容 AP 字段归零，历史共享日志中的 AP 余额文字会被清理。地图尚未定义“助跑跳远”动作，因此运动健将的跳远增距仍为 DM 手动裁定。

游侠猎人审计：巨像杀手、巨人杀手、灭群者、逃离群攻、多重攻击防御、钢铁意志、万箭齐发、旋风攻击、反射闪避、逆流反击与直觉闪避均已进入 DM 权威 Headless 结算；逆流反击通过共享 Interrupt 由受击猎人选择改攻目标，并覆盖普通武器、借机、怪物／荒野变形、多重攻击、武僧附赠攻击及近战法术攻击。原初感知会消耗实际法术位并返回范围内的 SRD 生物类型；隐匿无踪、无踪步、野性感官的攻击劣势豁免与屠灭众敌也已接入角色状态或攻击结算。宿敌的追踪／知识检定、自然探索者的旅行收益、大地行者的地形与植物交互、无踪步的非魔法追踪，以及野性感官对通用隐形状态的定位仍依赖尚未建立的探索／地形／感知事务，当前明确交由 DM 裁定，不标记为自动结算。

野蛮人审计：狂暴的力量检定／力量豁免优势、近战伤害加值、物理伤害抗性、重甲限制、持续条件与主动结束均由 Headless 结算；降至0 HP或坚韧狂暴失败会立即结束狂暴，狂乱在任一结束路径只获得一次力竭。鲁莽攻击、危险感知、快速移动、凶蛮重击、坚韧狂暴、不屈力量、20级原始斗士，以及狂战士的狂乱、无心狂暴、威吓气势和报复均已进入实际属性、攻击、豁免、资源或反应事务。野性直觉的先攻优势已接入；其“受突袭时立即狂暴并行动”的例外仍需等待通用突袭回合限制，当前由 DM 裁定。

德鲁伊审计：荒野变形会验证已知野兽、等级对应CR／游泳／飞行限制、动作和次数，采用独立形态生命池与野兽物理属性、AC、速度、豁免和攻击，形态归零、主动恢复或时限结束都会恢复原始数据；20级大德鲁伊不消费变形次数。18级前在形态中施法会同时被地图准备层与 Headless 拒绝，18级“野兽施法”解锁该限制。大地结社的额外戏法、结社法术、自然恢复、自然结界和自然庇护已进入选项、休息、免疫或目标攻击豁免事务。德鲁伊语、不老身躯、金属装备忌讳、大地行者的困难地形／魔法植物交互，以及大德鲁伊对有价格或会消耗材料成分的例外，仍依赖尚未结构化的语言、年龄、地形和法术成分系统，由 DM 裁定。

武僧与散打宗审计：无甲防御、武艺骰与敏捷攻击、武艺附赠攻击、气点、无甲移动、额外攻击、拨挡飞矢及掷回、疾风连击、耐心防御、疾风步、震慑拳、真气驻拳的规则标识、反射闪避、心如止水、百病不侵、金刚魂全豁免熟练／失败重掷、空灵体与超凡入圣均已有属性、资源、攻击、防御或先攻恢复路径；散打技法三种效果、身心合一、宁静心境和渗透劲也由 Headless 结算并跨多端持久化。轻身坠、疾风步的跳跃翻倍、9级沿垂直表面／液体移动、日月语、不老身躯与空灵体的星界投影分支，分别需要坠落、跳跃、立体地形、语言、年龄和位面系统，当前明确为 DM 手动裁定。

游荡者与盗贼审计：专精、偷袭的武器／优势／邻接条件与每回合一次限制、巧妙动作、直觉闪避、反射闪避、可靠才能、感知豁免熟练、飘忽不定和幸运一击均已接入 Headless；偷袭按“回合”而非“轮”记录，因此借机攻击发生在其他生物回合时可再次合法触发。盗贼的快手、高超潜行和盗贼反射已有动作、检定或第二先攻槽路径。通用躲藏值现在参与服务端 Token 安全投影，并以观察者的被动察觉决定是否下发；攻击事务会统一暴露躲藏者。盗贼黑话、盲感的特殊感官定位、飞檐走壁的攀爬／跳跃、使用魔法装置的物品装备门槛，以及快手所选具体物品效果，仍需要语言、特殊感官、攀爬／跳跃与结构化物品事务；当前保留规则数据和辅助判定，由 DM 裁定，不能标记为自动完成。
