# 怪物 Headless 覆盖率真值与 Ratchet

运行：

```powershell
node scripts/audit-monster-headless-coverage.mjs
node scripts/audit-monster-headless-coverage.mjs --json
```

扫描固定读取 `DND5E_SRD_MONSTERS`，按目录顺序产生确定性结果。脚本在任一最低覆盖率回退、未自动化上限增加，或目录总数发生未审阅变化时以非零状态退出。相同的校验也由 `monsterHeadlessCoverage.test.ts` 执行。

## 什么才算完整自动化

- **动作**：动作必须通过结构校验。武器攻击需要可执行的攻击/伤害或命中附效；其他动作需要结构化规则；多重攻击的每个子动作还必须能由组合事务执行。仅名称或描述中出现“攻击”“多重攻击”等文字不会计为 Headless。
- **法术**：法术 ID 必须对应结构化核心定义，且该定义通过怪物施法兼容性门禁。只有描述文本、只有显示名称，或仍含未结构化持续/专注/特殊击杀语义时，只会归入 `manual` 或 `missing`。
- **特质**：必须同时有明确的 `automation: 'headless'` 和结构化 `rule`。仅将特质命名为“魔法抗性”等不会提高覆盖率；有 Headless 声明但没有规则会被单列为未证实声明，并由上限 0 阻止合入。

Ratchet 常量位于 `monsterHeadlessCoverage.ts`。当实现新增自动化后，应在测试证明规则可以执行的同一改动中提高最低值或收紧上限；不要为了让测试通过而降低最低值。

本轮优先消除了直接改变胜负的缺口：完整多重攻击、成年/远古龙翼击、Healing Touch、可自动表达的传送与隐形动作、石化吐息、范围缓慢、雷电打击、震慑尖啸和传奇凝视，以及睡眠术、雷鸣波、次级复原术、纠缠术、解除魔法、人类定身术、放逐术、持续伤害区域和常用战斗增益法术。Blink Dog 与 Unicorn 的复合传送、Darkness 的跨区域三维视线、Cloudkill 的移动/风驱散等尚无完整规则证据的内容继续保留 DM 裁定，不虚标为 Headless。
