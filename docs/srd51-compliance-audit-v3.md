# SRD 5.1 合规审计报告（第三次增量）

审计日期：2026-07-20
规则基线：D&D 5e 2014／SRD 5.1
前序基线：`docs/srd51-compliance-audit-v2.md`

本报告只记录第二次审计后的已验证变化，不把“规则数据已存在”当成“已接入 Headless”。插件清单协议仍是 Rules Plugin API V2；这里的 V3 指第三次合规审计，不是插件 API 版本升级。

## 本轮结论

第二次审计中选定的五项规则缺口已经关闭：2014 附赠动作法术对反应法术的双向限制、擒抱自动解除、倒地匍匐选择、冻寒之触完整骑乘，以及插件戏法按总基础骰数升级。五项都在 DM 权威 Headless 边界处理，并有单元测试覆盖。

E2E 基线已与当前房间、角色归属、初始装备、规则工作室和插件握手流程对齐。20 个现有 E2E 场景的累计验证全部通过；共享临时目录在每次套件运行前重建，旧房间和旧资源不再污染下一次运行。

## 地图 Hook 与权威订阅

地图页的共享战斗、骰子、日志、中断、玩家行动 ACK 和敌方回合调度已改为使用稳定地图 ID，并在副作用执行时读取最新 Store／Effect Event。这样不会因旧闭包把上一张地图、旧 Token 或旧回合写回当前权威状态。

Token 坐标首次挂载与后续同步已分离：首次坐标只在组件挂载时设置，之后仍使用 Konva 补间；修复 Hook 依赖没有把移动动画退化为瞬移。相关地图组件的 Hook lint 必须保持零警告。

## 持续区域声明式编辑器

DM 规则包工作室现在可以为范围特性编辑持续区域触发器：

- 首次创建、进入区域、目标回合开始、目标回合结束；
- 同一目标每轮一次，或允许每次进入都触发；
- 使用来源角色法术 DC 或固定 DC 的属性豁免；
- 豁免成功无效或伤害减半；
- 白名单伤害骰、伤害类型、标准状态及 ActiveEffect 解除／重复豁免；
- 提交前建立 `dm-adjudication` Interrupt 供 DM 调整。

同一次移动内反复进出同一个不连续区域时，`oncePerRound` 会在候选收集阶段去重；关闭该选项时才允许多次触发。编辑器只生成纯数据，Host 继续负责路径检测、骰子、抗性／易伤／免疫、状态免疫、收据、专注清理和多端同步。

当前持续区域编辑器首先服务于 `registerFeature().action.persistentArea`。插件法术仍只有单目标事务，不能仅靠填写范围外观就宣称为完整范围法术；法术级区域需要先扩展权威多目标法术事务和地图模板绑定。

## 仍未关闭的边界

本报告不撤销第三轮代码审查中尚未修复的其他条目。优先级仍包括怪物特性规则化、几何视线与攻击可见性统一、预备动作触发入口、擒抱／推撞体型与挣脱动作、昂贵材料和多目标插件法术，以及更多 SRD 法术的专用 Headless 结算。

任何未经过地图交互、DM preflight、骰值校验、行动／资源原子消费、效果应用、ACK 和多端恢复完整链路的内容，都必须继续标记为“DM 裁定”。
