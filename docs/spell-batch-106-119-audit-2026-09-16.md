# 法师测试批次规则核查（2026-09-16）

范围：蛛行术，以及截图 106–119 中属于法师的十个法术。对照项目内经审核的 SRD 5.1 中文描述、当前执行代码、原 UI 报告。历史报告的“通过”不作为当前版本完整通过的证明；其中的旧策略说明也不作为本次修改授权。

本次仅检查和记录，没有改动法术规则或角色数据，也没有逐个进行当前双端 UI 实测。

## 已确认应修正

后续修复记录：臭云术已改为回合开始时全身在云内才触发；按用户要求不修改无需呼吸与风力计时。阳炎爆已接入玩家、怪物共用的地图结算，按物理阻挡和高度判断法术黑暗交集，并同步清理对应专注；怪物端补充自动施法和失败目盲。场景黑暗仍由 DM 删除。相关 262 项测试与构建通过；以下保留原审计发现。

### 臭云术

- 描述要求生物整个身体都在云中开始回合；当前回合触发用 `dnd5eTokenIntersectsPersistentAreaAt`，占据格只要有一个相交便算进入。大型生物擦边也可能被要求豁免。
- 当前自动成功仅检查毒素伤害免疫，没有“无需呼吸”自动成功分支；自动成功仍在请求并解析豁免骰后处理，需要将免投骰预检前置。
- 风力驱散只有通用强风区域相交即移除，没有完整实现中风四轮、强风一轮计时。应保留风墙等法术自己的特殊驱散规则，不能简单把所有驱散改成延迟。
- 毒素相关豁免优势的上下文仍需专项回归，不能仅凭体质豁免和毒素伤害免疫认为完整覆盖。

证据：`src/rulesets/dnd5e/coreSpellAreas.ts` 的 stinking-cloud 声明；`persistentAreaGeometry.ts:150`；`pluginAreas.ts:669,1168`；`headlessCombatEngine.ts:34066`。

### 阳炎爆

- 玩家施法页面有解除法术黑暗的补充结算，但 `settleSunburstSpellDarknessDispels` 当前仅有这一个生产调用点，怪物施法与独立 Headless 结算不共享它。
- 解除判定只按锚点半径检查黑暗格子，不使用已被墙体裁剪的本次实际影响格和垂直范围。墙后黑暗仍可能被解除。
- 应放入公共结算，使用实际受影响空间。按此前用户确定的设计，DM 绘制的场景魔法黑暗仍交给 DM 删除，不列为本法术的自动清除对象。

证据：`src/pages/MapsWorkspacePage.tsx:29291`；`src/pages/maps/spellSettlementCoordinator.ts:808`。伤害、失败目盲、回合末重豁免、亡灵与泥怪劣势已有实现。

### 心灵联结

- 通讯服务从 selectedMapId 取角色，要求所有参与者在当前地图，错误地限制了“同位面、不限距离”。同位面的不同地图之间会丢失联结接收者。
- 该通讯分支没有实际位面比较，同地图上的以太位面角色也不能靠此实现得到正确隔离。
- 应按联结成员与真实位面筛选，地图切换不能替代位面判定。

证据：`scripts/shared-server-core.mjs:3936–3962`；`src/pages/CommunicationsPage.tsx:148–154`。目标上限八个、智力大于二、持续一小时、非专注与联结标记已有实现。

## 自动化尚未完整，建议补确定性规则

### 暗示术

2026-09-17 跟进：已接入施法者或同伴实际造成伤害即解除的来源关联机制，同时结束对应专注。回归覆盖施法者、同伴、无关敌人、未命中、伤害免疫和临时生命值吸收伤害；下文为初始审计记录。

当前属于 partial Activity，仍带人工裁定边界。不能将感知豁免或消耗资源视为整段规则完成。建议补明确的暗示状态、可听见/理解语言、魅惑免疫、施法者及同伴造成伤害即结束、任务完成时手动结束、最长八小时与专注结束清理。暗示是否合理、是否明显自害由 DM 语音裁定，无需让系统理解自然语言。

### 心灵遥控

当前仍属对抗检定/强制移动/物体交互的部分自动化。生物分支可补：施法属性检定对抗力量检定（不是力量豁免）、巨型及以下、每轮动作、最多移动三十尺且不超六十尺射程、悬浮与束缚至施法者下回合结束、换目标清除旧目标效果。物体形状、重量和精细操纵保持 DM 处理，不能据此将整个生物分支也省略。

### 魔法徽记

当前部分自动化不等于八种模式完整完成。建议有一个持久徽记记录，DM 可手动触发；触发后统一启动十分钟、六十尺范围，以及触发时/首次进入/回合结束触发。八种模式各自的豁免、伤害、状态和解除条件应结构化。开放触发条件、发现徽记和物体移位由 DM 处理。材料需求中已有一千金币消耗材料条目；仍需用真实施法验证一分钟与材料消费只执行一次。

### 传送术

当前属于随机表、跨场景、熟悉度的人工边界。不是本次确认的错误自动结算，而是可补自动化：DM 指定熟悉度后系统掷 d100、重复灾难时每次 3d10 力场伤害、偏离的两枚 d10 与方向 d8；保留 DM 决定目的地及换图。需要注意“施法者自己加至多八名同伴”，不能把施法者算进八人上限。

这四项证据：`generated/srdSpellHeadlessDecisions.generated.json`；`activities/dnd5eSrdAuditedSpellActivities.ts` 的 partialActivity 和通用裁定分支。这里列的是尚未闭环的规则，不声称每项均已在 UI 重现。
