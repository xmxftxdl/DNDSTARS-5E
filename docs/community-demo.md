# 星痕社区交互演示

入口：http://127.0.0.1:5273/community-demo/index.html（5274、5275 同路径）。

源码位于 `public/community-demo/`，独立静态页面，无新增依赖。Vite 开发服务器可直接访问；正常构建会将其复制到 dist。本次只向现有 dist 复制该目录，不重新构建或替换游戏应用。测试：`node --test scripts/community-demo.test.mjs`。

## 本版实现

- 规则板块：DND、COC、三角机构、匕首之心。主题再按规则讨论、跑团战报、开团招募、原创分享、新手求助筛选。
- 主题搜索、排序、详情、本地发布、回复与收藏。
- 资源：模组、怪物、地图、Token、音效、插件；按规则和类型筛选，展示作者、版本、介绍、授权说明。
- 资源投稿表单保存介绍和文件名，显示待审核；文件本身不上传。提供演示说明 JSON 下载，不提供真实安装或房间导入。
- 每日签到 +2 钱币，按北京时间日期去重；支持主题扣 1 钱币，同帖一次，不能支持自己，余额不足拒绝。收支明细可查看。
- 钱币只消耗，不转入作者余额，不直接兑换 AI 点数。优质主题、资源与活跃贡献进入独立奖励审核方案。
- 数据存放在当前浏览器、当前端口的 localStorage；不同端口不共享余额。所有内容均为示例，不连接真实账号。

## 防刷边界

本演示的客户端去重仅用于展示交互，不是安全机制；本地日期、存储和源码均可修改。正式版需要服务端身份认证、事务账本、唯一事件约束、注册与请求限流、异常行为复核、账号观察期、奖励预算和申诉机制。不能依赖客户端余额、单一 IP 或支持次数直接发放 AI 奖励。

建议服务端签到唯一键 `(user_id, Beijing_date)`，支持唯一键 `(user_id, topic_id)`。扣币、支持记录与流水必须在同一事务完成。AI 奖励使用独立审核事件和幂等键，保留审核原因及撤销记录。
