## 二、本轮新发现：高严重度（6 项）

### N-H1. 生成器丢失传奇抗性次数，全部 32 只传奇怪物的自动传奇抗性失效
`scripts/generate-srd-monsters.mjs:273-274`

生成器先把 `special_abilities` 映射成只含 `{name, description, automation}` 的 traits，再从映射后的对象读 `usage.times`——字段已被丢弃，永远 undefined；正则回退匹配的是特性名（上游名字是纯 "Legendary Resistance"，次数在 usage 里），也永不命中。生成物中 `legendaryResistanceUses` 出现次数为 0。引擎和 UI（传奇抗性豁免弹窗）都已接好线，唯独数据源断供。
**修复**：映射前从原始条目读 `usage.times`，重新生成目录；补一条"传奇怪物必须携带 legendaryResistanceUses"的生成物回归测试。

### N-H2. 伤害段被静默丢弃后攻击仍标 headless，自动结算系统性少算伤害
`scripts/generate-srd-monsters.mjs:111-118、146-150`

`normalizedDamage` 无法解析的条目直接过滤，且无"描述 vs 结构化数据"一致性检查。已核实的实例：djinni 弯刀丢失 1d6 雷电/闪电附伤、flying-snake 丢失主穿刺伤害（只剩毒素，对毒免疫生物 0 伤害）、pit-fiend 钉头锤丢失 6d6 火焰（每击少算约 21 点）。全部仍标 `automation: 'headless'` 参与自动结算。
**修复**：统计描述中 `plus N (` 次数与结构化段数比对，不一致或丢弃过条目时强制降级 `dm-adjudication`；重新生成。

### N-H3. 突袭门禁误拦死亡豁免等豁免类动作
`src/rulesets/dnd5e/headlessCombatEngine.ts:6891` + `MapsPage.tsx:13210-13224`

放逐门禁显式豁免了 `death-save`、`monster-undead-fortitude-save`、`monster-on-hit-save` 等，但紧随其后的突袭门禁对除 `end-turn` 和野性直觉外的一切动作返回失败。被突袭生物在首回合结束前被打到 0 HP 时，死亡豁免被拒绝；MapsPage 的"自动跳过受突袭回合"分支还会把濒死者的死亡豁免回合整个跳过。SRD 突袭只禁移动/动作/反应，不禁豁免。
**修复**：突袭门禁复用放逐门禁的同一份豁免白名单；跳过分支先判濒死。

### N-H4. 持续区域移动不接回合经济，可无限次移动月光束/炽焰法球
`src/rulesets/dnd5e/coreSpellAreaAction.ts:20-70`

`prepareDnd5eCoreSpellAreaMove` 不接收 `turnEconomy` 也不写入 `combatant.turn`，快照里的战斗员永远是满资源，引擎扣减永远成功。施法者用掉动作后仍可移动月光束；同一回合可反复用"附赠动作"移动炽焰法球并多次结算撞击 2d6。
**修复**：prepare 增加 `turnEconomy` 参数并写入快照（与 `playerBasicAction.ts:140` 同模式）；MapsPage 路由传入实时经济。

### N-H5. 强制位移不结算持续区域触发，"推进棘刺丛生"完全无效
`MapsPage.tsx:7737-7743（推撞）、9595 一带（法术强制位移）`

`on-enter`/`on-move-distance` 触发只在玩家/怪物主动移动路径上收集；推撞和雷鸣波/斥力魔爆的 `forcedMovements` 直接改坐标，不收集触发。"把敌人推进棘刺丛生每 5 尺 2d4"正是该法术核心用法；被推入月光束/灵体守卫也属于"进入区域"（2014 勘误只豁免"区域移到生物身上"，不豁免生物被动位移）。
**修复**：强制位移落点确定后用同一 `collectDnd5ePersistentAreaTriggers` + `settleDnd5ePersistentAreaCandidates` 收尾。

### N-H6. 法术攻击 prepare 缺帮助/恐惧判定，引擎用 0 顶替第二骰
`src/rulesets/dnd5e/spellAction.ts:520-532` + `headlessCombatEngine.ts:5478`

上轮 M1 的修复（60f92a2）只覆盖了装备攻击和借机攻击。法术攻击 prepare 仍缺 `dnd5eHelpAttackApplies`/`dnd5eFrightenedAttackDisadvantage`，而引擎结算有；冲突时 `rolls = [d20, action.d20Second ?? 0]`——劣势取 min 后有效 d20 为 **0**，攻击几乎必失手且与玩家看到的骰面不符。
**修复**：prepare 补齐两项来源；引擎回退 `?? 0` 改为 `?? d20`。
