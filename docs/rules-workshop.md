# DM 规则包工作室

“规则插件”页面内置规则包工作室，用同一份表单草稿生成一个自包含的 `.dndstars5e` 文件。工作室目前可编辑：

- 种族：速度、固定属性调整和任选属性调整。
- 背景：最多两项技能熟练、工具熟练、额外语言、说明和背景特性。背景技能会进入角色存档与 Headless 熟练快照。
- 特性：名称、等级、摘要和规则正文。默认是 `manual`，由玩家在人物卡“扩展规则”页选择；也可以开启 Headless 效果编辑器。
- 法术：环级、学派、职业、施法时间、射程、V／S／M、仪式、专注、持续时间、正文和升环说明。可保留为 `reference-only`，也可在“法术效果编辑器”中声明 Host 可验证的伤害、命中／豁免、升环和状态效果。
- 装备／物品：武器、护甲、盾牌、饰品和治疗消耗品。固定命中、伤害、AC、豁免和速度修正由 Host 投影进 Headless；“装备效果编辑器”还可创建带实例充能的攻击骰重掷装备。
- 属性生成：标准数组、购点成本表和投骰规则。

## 保存与发布

“保存本地草稿”把表单状态保存到当前浏览器；“载入本地草稿”恢复它。“下载插件文件”生成可迁移的 `.dndstars5e` 文件。DM 使用“保存、启用并发布”时，文件会经过与手动上传相同的 Worker 初始化、Host schema 校验、SHA-256 固定和房间规则握手；玩家自动下载并激活精确版本。

本地草稿只是编辑便利，不是云存档。需要换设备时应下载插件文件；角色云存档仍按房间规则包 ID、版本和哈希进行兼容性检查。

## 自动化边界

表单不接受 JavaScript resolver。插件不能访问 DOM、网络、localStorage、IndexedDB 或内部 Store。静态装备和法术效果都由 Host 白名单事务执行；未开启编辑器或超出当前白名单的内容仍保守地进入 DM 裁定。

自定义特性的 Headless 效果编辑器支持：

- 动作、附赠动作、反应或免费行动。
- 自身、单一生物，以及圆形、锥形、线形和矩形地图模板。
- 公开的伤害骰与治疗骰；伤害会统一经过 Host 的抗性、易伤和免疫处理。
- 标准状态、剩余轮数、解除时点，以及目标回合结束时的重复豁免。
- DM、行动者或目标回答的 Interrupt 确认；取消或超时不会提交效果事务。

生成器只把这些表单项编译成 `registerHeadlessAction` 的骰子声明和 capability 调用。玩家选择目标后，DM Host 会重新检查规则包版本、特性归属、行动经济、阵营关系、距离与范围模板，再把解析请求交给 Worker。Worker 只能返回伤害、治疗和标准状态操作，不能直接修改战斗状态。

## 法术效果编辑器

开启法术 Headless 后，Host 会以法术本身的职业归属、环级、施法时间、射程、成分和持续时间为权威输入，并在一次 `CombatTransaction` 内完成：

- 检查已学习／已准备、当前规则包版本、动作或附赠动作以及对应法术位。
- 检查 V／S／M 声明；普通材料成分要求角色持有材料包或合法法器。
- 由 Host 公开掷法术攻击、目标豁免与伤害骰，并写入 `RollLedger`。
- 处理重击、豁免成功减半／免伤、升环伤害、抗性、易伤和免疫。
- 原子扣除法术位，施加标准状态，并启动或替换专注。
- 固定轮数、下一回合边界和“目标回合结束重复豁免”会创建原生 `ActiveEffectInstance`，不会退化成永久状态字符串。

当前编辑器自动结算范围是“自身或单一目标”。范围法术、多枚独立飞弹、额外目标升环，以及有价格或会被消耗的材料仍应保留为 DM 裁定；在货币／材料实例事务完成前，Host 会 fail closed，不能用普通法器绕过昂贵材料。

## 装备效果编辑器

第一条纵向切片是“4 点充能，攻击骰公开后可重掷一枚攻击 d20”：

- 充能属于具体库存实例，而不是物品模板或角色全局计数；实例资源归零后物品仍保留。
- 只有已装备且还有充能的武器能在攻击骰公开后开启行动者 `InterruptWindow`。
- 选择使用后由 DM Host 重掷指定 d20，必须采用新结果，并在同一事务提交后扣除 1 点充能。
- `RollLedger` 同时记录原骰、新骰、装备来源和资源消费；取消、失败或回滚不会扣充能。

目前编辑器只开放这条已完成端到端验证的主动装备效果。额外伤害、命中后状态、充能施法、每日重置和同调依赖仍需逐项加入 Host capability，不能只靠描述文字获得自动结算权限。
