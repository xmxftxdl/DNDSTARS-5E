# DM 规则包工作室

“规则插件”页面内置规则包工作室，用同一份表单草稿生成一个自包含的 `.dndstars5e` 文件。工作室目前可编辑：

- 种族：速度、固定属性调整和任选属性调整。
- 背景：最多两项技能熟练、工具熟练、额外语言、说明和背景特性。背景技能会进入角色存档与 Headless 熟练快照。
- 特性：名称、等级、摘要和规则正文。UI 创建的特性默认是 `manual`，由玩家在人物卡“扩展规则”页选择。
- 法术：环级、学派、职业、施法时间、射程、V／S／M、仪式、专注、持续时间、正文和升环说明。UI 创建的法术默认是 `reference-only`，会进入对应职业法术书，但具体效果走 DM 裁定。
- 装备／物品：武器、护甲、盾牌、饰品和治疗消耗品。固定命中、伤害、AC、豁免和速度修正由 Host 投影进 Headless。
- 属性生成：标准数组、购点成本表和投骰规则。

## 保存与发布

“保存本地草稿”把表单状态保存到当前浏览器；“载入本地草稿”恢复它。“下载插件文件”生成可迁移的 `.dndstars5e` 文件。DM 使用“保存、启用并发布”时，文件会经过与手动上传相同的 Worker 初始化、Host schema 校验、SHA-256 固定和房间规则握手；玩家自动下载并激活精确版本。

本地草稿只是编辑便利，不是云存档。需要换设备时应下载插件文件；角色云存档仍按房间规则包 ID、版本和哈希进行兼容性检查。

## 自动化边界

表单不接受 JavaScript resolver。插件不能访问 DOM、网络、localStorage、IndexedDB 或内部 Store。静态装备效果由 Host 白名单执行；特性和法术默认保守地进入 DM 裁定。若要实现伤害、状态、区域或反应自动化，必须使用 Plugin API V2 的受控 Headless Action、骰子声明和 capability，并经过 DM 权威 preflight。
